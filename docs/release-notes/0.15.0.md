## 本次重点

「发行说明」页（帮助 → 显示发行说明，或命令面板里搜索「显示发行说明」）重新排版：每个版本独立成区块，页面顶部提供版本索引，正文里的文档与常用入口可以直接点开。同一个版本在应用内、下载页和 GitHub 上读到的介绍自此完全一致；历史版本的既有内容一字未改。

## 发行说明页

- 每个版本一个区块：版本号与发布日期独立成头（新版本还带标题与一句话摘要），连续翻阅多个版本时不再糊成一整篇。
- 页面顶部新增版本索引，一键跳到指定版本；升级后弹出的「新功能」窗口使用同一套版式。
- 正文里指向随包文档的链接可以直接点开，在编辑器内离线阅读，不必再复制地址到浏览器。
- 「打开设置」「键盘快捷方式」「颜色主题」「显示语言」这类入口可以直接点，点击即在编辑器里执行。
- 外部网页链接交给系统默认浏览器打开；同一篇说明内部的标题锚点可以直接跳转。
- 某条说明引用的文档在当前安装里不存在时（例如读的是更早版本的说明），会明确提示并提供该版本文档在 GitHub 上的链接，而不是跳到不相关的位置。
- 不在允许范围内的链接（脚本协议、相对路径等）不会被打开，而是给出提示，避免误开本机文件。

## 下载页

- 下载页的「更新说明」区改为按版本列出标题与摘要，并可进入「全部版本介绍」查看每个版本的完整正文。
- 该区只展示已经正式发布的版本，不会提前出现尚未发布的版本。
