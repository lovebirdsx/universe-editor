## 本次重点

这个版本把「拉取」和「更新」这两件日常事的可见性补齐了。Perforce 新增[拉取历史记录](doc:perforce/sync-history)页：每次拉取的耗时、文件数、走的引擎、从哪个入口发起都留了底，失败与取消也各记一条，还能一键导出 CSV；配套的 p4delta 加速引擎不再需要手动安装——找不到时编辑器会自己下载维护一份（仅 Windows x64），装好即生效。扩展方面新增更新提示与自动更新：有新版本时活动栏出现数字徽标，扩展视图给出可一键更新的提示条。AI 用户还可以在会话里直接重放 MCP 工具调用来做调试。

## Perforce

- 新增**拉取历史（同步历史）**页：命令面板搜索「Perforce: 查看同步历史」，或点 Perforce 图谱工具栏刷新按钮旁的 🕘 图标（「整个仓库」图谱与「文件 / 文件夹历史」打开的是同一页）。每一次拉取各记一条——成功、失败、取消、已是最新都在内。
- 每条记录给出结果、开始时间与耗时、六类文件计数、执行引擎与目标修订、触发入口（资源管理器 / 状态栏 / 图谱 / 时间线 / 命令面板 / 自动重试），以及这次 p4 进程的读写字节与文件监视器观察到的落盘事件数。
- 列表默认加载最近 50 条，底部「加载更多」继续往前翻；列表与详情之间的**分隔线可以左右拖动**，宽度会被记住；**导出 CSV…** 把全部记录（最多 200 条）写成一个文件，Excel 直接打开不乱码。
- 记录只存在本机（保留最近 200 次拉取，同一台机器的多个窗口共享），这个页面纯读取：不调用 p4、不联网、不上传。
- **编辑器可自动安装 p4delta 引擎**：机器上找不到现成 p4delta 时，编辑器会在后台下载并维护一份（仅 Windows x64），装成或升级成弹一次通知（带「显示日志」）。查找顺序是「环境变量 → 设置 → PATH → 默认安装位置 → 编辑器自装副本」，前四级任意一处命中就完全不联网。
- 想手动装或升级：命令面板搜索「Perforce: 安装或更新 p4delta」——它跳过自动安装开关与检查节流，即使已有自装副本也会照装，适合主动升级或关掉自动安装后的手动路径。相关设置：`perforce.p4delta.autoInstall`（默认开，关掉表示改为手动安装）、`perforce.p4delta.downloadBaseUrl`（连不上公网的机器可指向自建镜像，摘要校验同样强制）。
- 修复：p4delta 装好或升级后本次会话没生效的问题——此前启动那轮检查跑完后整会话都停在原生引擎，现在装完即重新启用，不需要重启编辑器。

## 扩展

- **更新提示**：编辑器在后台自动检查扩展更新（启动后一次，之后每 12 小时一次），发现新版本时从四个地方告诉你——活动栏扩展图标上的数字徽标、扩展视图顶部的「有 N 个扩展可更新。」提示条（带「全部更新」按钮）、条目右侧的「更新到 v…」按钮、详情页的 `v当前版本 → v新版本`。
- 想只看待更新的扩展，在扩展视图搜索框输入 `@updates`（别名 `@outdated`）。
- **更新全部扩展**：命令面板搜索「扩展: 更新全部扩展」，或用视图标题栏的更新按钮。多条更新合并成一次提交，扩展宿主只重启一次，装好几秒内生效，不需要重启编辑器。
- **自动更新默认开启**：只作用于市场来源的扩展（本地 .vsix 安装的、内置的、开发中的都不参与）；扩展新版本发布后默认等 2 小时才自动装上，避免刚发布的坏版本第一时间进到你的环境，想立刻用就点条目上的更新按钮。
- 相关设置（在设置编辑器搜索 `extensions.autoUpdate`）：`extensions.autoCheckUpdates`（是否自动检查，默认开）、`extensions.autoUpdate`（是否自动安装，默认开）、`extensions.autoUpdateDelay`（发布后等待多少小时，默认 `2`）。也可以对单个扩展关闭自动更新：条目齿轮菜单（或右键）→「自动更新」，该开关只存本机，不随远程工作区同步。
- 自动更新走的是与手动安装完全相同的一套闸门（发布者信任、签名验证、恶意拦截、版本兼容），不会因为「是自动的」而放宽。详见[扩展](doc:customization/extensions)。
- 修复：检查时连不上扩展市场，不再显示成「已是最新」，而是明确报「无法检查扩展更新」并给出重试按钮；扩展升级后不再残留旧版本记录与目录（此前可能出现重复条目）。

## AI 与 Agent

- **MCP 工具调用重放**：会话里每个 MCP 工具调用卡片的顶栏新增重放按钮（在耗时左边），命令面板「MCP: 调试工具调用…」对当前会话最近一次调用走同一流程。点击后先弹二次确认（写清服务器、工具与参数摘要，密码 / token 之类字段会掩码），确认后打开独立调试页签：查看该服务器提供的工具与参数 schema、改参数重跑、看服务器自己的报错、断开重连、从调用历史把上次参数填回来。
- 注意：重放**绕过 Agent 的权限确认**，等于你手动执行了那个工具；它与 Agent 的连接相互独立，同一个服务器会被拉起第二个进程。远程工作区、其它工作区的只读会话预览，以及需要交互式登录（OAuth）的服务器暂不支持。
- 细节见[技能、记忆与 MCP](doc:ai-agent/skills-memory-mcp)。

## Git

- 分支还没发布、手上又没有要提交的改动时，源代码管理侧栏的提交按钮会直接变成**发布分支**，点一下完成首次推送，发布后按钮自动恢复。push 因没有 upstream 失败时，编辑器会询问是否发布该分支（可选择不再询问）。见[分支与合并](doc:git/branches-and-merge)。

## 升级注意事项

- **「扩展: 检查扩展更新」不再自动安装更新**，只报告结果并给出更新入口。想要自动化的，可以依赖默认开启的自动更新，或手动点「全部更新」。
- 扩展**自动更新默认开启**（市场来源、发布后延迟 2 小时）。不希望后台自动装扩展的话，把 `extensions.autoUpdate` 关掉，或对单个扩展关掉「自动更新」。
- Perforce 的 **p4delta 自装副本默认开启且会联网下载**（仅 Windows x64）。内网或离线机器可关掉 `perforce.p4delta.autoInstall`，或用 `perforce.p4delta.downloadBaseUrl` 指向自建镜像。
- MCP 重放**绕过 Agent 的权限确认**，执行前请在确认框里看清目标服务器与工具。
