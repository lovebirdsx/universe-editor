## 本次重点

Perforce 拉取的过程更清楚了：状态栏把进度单独列成一条，客户端名条目始终打开图谱；由 p4delta 执行的拉取还会显示引擎当前所处的阶段。强制拉取多了一个可选动作——把范围内未跟踪的本地文件一起删掉。Git 图谱可以流式加载完整历史；AI 会话时间线换上了更顺手的 `j` / `k` / `a` / `e` 滚动键。

## Perforce 拉取与状态栏

- **进度单独一条**：p4 长操作进行时，状态栏会在客户端名条目右侧临时出现一条进度条目，完成后自动收起。客户端名条目本身不变，点它始终打开 Perforce 图谱——不会再在拉取中变成取消按钮。可取消的操作点进度条目才会弹确认；不可取消时该条目不响应点击。见[拉取版本与状态感知](doc:perforce/sync-and-status)。
- **看得见 δ 在哪个阶段**：由 p4delta 执行的拉取会在计数与速率之间多显示一个引擎自己的阶段词，形如 `Syncing 0 · scan · 042MB/s · 12s`，悬停可见「阶段 2/7：scan」。强制拉取的大半时间花在 `scan`，此前条目上只有停着的 0，阶段词是此时唯一在变的东西。阶段词是引擎原词，不翻译。
- **扫描段也有速率**：Windows 上读 / 写计数器都不动时，速率回落到第三个「其他」计数器，强制拉取开头的扫描段不再一直显示 `000KB/s`；悬停时读取 / 写入 / 其他三个累计值分列显示。Linux 上「其他」恒为 0，不是「没在扫描」。
- **强制拉取可一并删除未跟踪文件**：这次强制拉取由 p4delta 执行时，确认框会多一个「强制拉取并删除未跟踪文件」按钮。它只删范围内、depot 从未跟踪、且未被 `.p4ignore` 覆盖的本地文件；范围外与被忽略的文件保留。删除不可恢复，只用普通「强制拉取」则不会删任何文件。p4delta 不可用或版本不支持时不会悄悄退回原生，而是如实报错。见[拉取版本与状态感知](doc:perforce/sync-and-status)。
- **p4delta 需要 0.1.19 或更新**：低于门槛或读不出版本时回退原生 p4，并在 Perforce 输出里说明原因；托管副本低于门槛时会绕过节流立即尝试升级。见 [Perforce](doc:perforce/resolve-and-advanced)。

## 同步历史

- **删除分开记**：目标修订里已经不存在的已跟踪文件记为「已同步删除」，不再混进「已更新」；「强制拉取并删除未跟踪文件」删掉的本地文件单独记「已删除 N 个未跟踪文件」。只有未跟踪删除、没有其它变化的一轮，结果仍记为已更新。旧记录没有这份拆分，按原样显示。见[拉取历史记录](doc:perforce/sync-history)。
- **CSV 新列**：`force` / `deleteUntracked` 说明这次是否强制、是否带删除未跟踪文件，删除数量在 `counts.untrackedDeleted` / `counts.trackedDeleted`。能力上线前的记录留空，不是 `false` / `0`。
- **打开就能用键盘**：同步历史页打开后焦点直接在左侧记录列表上，↑/↓ 切换记录，不用先点一下。

## Perforce 图谱

- **两条新命令**：图谱激活时可在命令面板运行 **Perforce Graph: 查询同步点** 与 **Perforce Graph: 跳转到同步点**，等价于摘要行的同步图标与点击 `#4521`。默认没有快捷键，可在「键盘快捷方式」里自行绑定；同步点仍是 `#?` 时，跳转命令只提示先运行查询，不会自动发起查询。见 [Perforce 图谱](doc:perforce/perforce-graph)。

## Git 图谱

- **加载全部提交**：列表底部新增「加载全部提交」（或命令面板 **Git Graph: 加载全部提交**），提交会流式追加，顶部显示「已加载 / 总数」进度与取消按钮。仓库超过 2 万条会先确认，单次最多 5 万条；取消后已加载的提交保留。提交很多时图谱自动启用虚拟滚动，滚动、搜索与键盘导航照常可用。见 [Git 图谱](doc:git/git-graph)。

## AI 会话

- **时间线滚动快捷键**：`j` / `k` 向上 / 向下滚动、`a` / `e` 到顶 / 到底、`Shift+K` / `Shift+J` 翻页；只移动视图，不改变选中卡片，按住可连续滚动。原来的 `Ctrl+Alt+↑/↓` 与 `Ctrl+Alt+PageUp/PageDown` 不再使用。见[管理会话](doc:ai-agent/managing-sessions)。
- **压缩卡片不再每 30 秒重来**：长时间压缩时，卡片的秒表与进度条不再因为引擎心跳每 30 秒归零重走。

## 编辑器与资源管理器

- **重命名后标签页跟随**：在资源管理器里重命名或移动文件 / 目录后，已打开的标签页原地跟到新路径，分屏位置、激活状态、未保存内容与视图状态都保留（文本、图片、差异、Markdown / HTML 预览）。
- **删除后焦点落到相邻项**：资源管理器、源代码管理、变更列表、搜索、会话、快捷键与扩展列表里，当前行被删掉后焦点落到下一项，删的是最后一项则落到上一项。
- **连续多选更稳**：修复 Shift+↑/↓ 连续多选时锚点漂移；多选后按 `Esc` 只保留当前焦点行。见[键盘快捷方式](doc:reference/keyboard-shortcuts)。
- **只查屏幕上的行**：资源管理器里的改动徽标、忽略变暗与落后服务器提示改为只查询视口内的文件行（侧栏隐藏时不查），不再为屏幕外的行逐个发起 p4 查询。

## 升级注意事项

- **会话时间线快捷键换了**：`Ctrl+Alt+↑/↓` 与 `Ctrl+Alt+PageUp/PageDown` 不再使用，改为 `j` / `k`、`Shift+J` / `Shift+K`、`a` / `e`。如果你在 `keybindings.json` 里给旧组合键绑过别的命令，需要自行确认。
- **p4delta 需要 0.1.19 或更新**：低于门槛或无法确认版本的副本不会被使用，拉取 / 收集回退原生 p4。自装副本不会自动升级，需要运行 **Perforce: 安装或更新 p4delta** 或更新自己的安装；自建镜像的 `latest.json` 版本也必须不低于 0.1.19，否则拒绝安装。
