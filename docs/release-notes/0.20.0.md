## 本次重点

编辑器现在可以把标签拖出成**独立的编辑器窗口**：多个窗口共享同一份工作区、文本模型与 AI 会话，标签可以在窗口之间移动或复制，窗口命令只作用于你正在操作的那个窗口。Agent 会话里新增了子 Agent 卡片的快速跳转，Git 图谱可以直接「同步工作树并推送 main」。

## 多窗口编辑

- **拖出建窗**：把标签拖到任何窗口之外再松开，会在松开的位置新建编辑器窗口，并把该编辑器移过去；窗口太靠屏幕边缘时会自动收回屏幕内。拖动途中按 `Esc`，或把标签拖回原窗口，都不会新建窗口。见[拖出标签与多窗口](doc:editing/tabs-and-split)。
- **跨窗口移动或复制**：把标签拖到另一个窗口的标签栏或编辑区即可移进去；拖到编辑区的左 / 右 / 上 / 下边缘，会先在那个窗口里分屏再放进去。拖动时按住 `Ctrl`（macOS 为 `Alt`）是复制而不是移动，未保存的改动也会一起带过去。
- **整组移动或复制**：在每个窗口的标签栏空白处右键，可以把整组编辑器「移动到新窗口」或「复制到新窗口」。
- **新建空窗口与收回**：命令面板可以运行 **新建编辑器窗口**；编辑器分散到多个窗口后，在任意窗口运行 **将编辑器恢复到主窗口**，会把所有辅助窗口里的编辑器合并回主窗口当前活动的编辑器组。
- **窗口命令跟着焦点走**：`Ctrl+Shift+W` 只关闭当前焦点所在的窗口，`Ctrl+=` / `Ctrl+-` / `Ctrl+0` 也只调整这个窗口的缩放，不会动其他窗口。
- **标题与通知归属各自的窗口**：辅助窗口标题显示它自己的活动文件（如 `notes.md — 编辑器窗口`），切换标签会跟着更新；点击辅助窗口里会话弹出的桌面通知，会把该窗口带到前台并跳到会话。主窗口标题仍只显示工作区名称。
- **资源管理器与选择器**：资源管理器只存在于主窗口；在辅助窗口按 `Ctrl+Shift+E` 会把主窗口带到前台并聚焦资源管理器。`Ctrl+Tab` / `Ctrl+P` 在当前窗口打开，高亮项可以指向其他窗口里的编辑器，选中后目标窗口会被激活并聚焦到该编辑器。切回辅助窗口时只把窗口带到前台，不会抢进编辑器。
- **关闭前保护未保存内容**：关闭辅助窗口时，未保存或需要确认的编辑器会先迁移到主窗口，而不是被直接丢弃；重新启动编辑器后，窗口位置与未保存内容也会按上次布局恢复。
- **可关闭拖出建窗**：不想要拖出建窗时，在设置里关闭 `workbench.editor.dragToOpenWindow` 即可，跨窗口拖动仍然可用。
- **窗口内操作更可靠**：在辅助窗口里复制文本或代码块不再失效；窗口最大化后编辑器画布会正常重绘；菜单、提示、对话框跟随所在窗口弹出；辅助窗口里的 Git 图谱不再把标题栏压扁。

## 子 Agent 导航

- **快捷键跳转**：`Alt+Shift+J` / `Alt+Shift+K` 在**顶层**子 Agent 卡片之间前后跳转，只聚焦卡片头部、不展开目标卡片；到末尾继续向后会环绕到第一张，只有一张卡片时两个方向都聚焦它。见[管理会话](doc:ai-agent/managing-sessions)。
- **`‹ n/N ›` 胶囊**：时间线右上角会显示当前聚焦（或视口位置）落在第几张子 Agent 卡片，序号随滚动更新；左右箭头与快捷键等价，同样首尾环绕。它只在会话里存在子 Agent 卡片时出现。
- **符号选择器里也能跳**：`Ctrl+Shift+O` 的符号列表会把子 Agent 卡片置顶为「子 Agent」分区，选中后只聚焦并滚动到卡片头部，不会展开它的子时间线。见[符号与定义](doc:search-navigation/symbols-and-definitions)。

## Git 图谱

- **同步并推送 main**：右键图谱中的工作树标记，选择 **将工作树同步到 {分支} 并推送 main…**。它使用与普通同步相同的选择器和跳过规则，流程结束后固定执行 `git push origin main`——即使有工作树被跳过或重置失败也照常推送；推送结果会追加到最终汇总，失败时另外弹出带 git 错误详情的通知。见 [Git 图谱](doc:git/git-graph)。

## 其它改进

- **压缩只占一张卡片**：上下文压缩进行中与完成后始终是同一张卡片，完成态会显示总用时与压缩前后的 token 变化（如 168k → 21k tokens）。见[模型与费用](doc:ai-agent/models-and-cost)。
- **Markdown 表格不再逐字折行**：长类型名等代码内容会保留必要宽度，表格过宽时可以横向滚动查看其余列，中文说明仍自然换行。见 [Markdown](doc:editing/markdown)。
- **网关模型切换不再等待**：Claude 会话切换网关模型时不再额外发送校验请求，省掉约 5 秒的等待，也不会改写你的 `settings.json`。切换成功不代表网关可用性已验证，实际能否调用以发送消息时的结果为准。见[模型与费用](doc:ai-agent/models-and-cost)。
- **最近工作区不存在时不再卡住**：打开最近工作区时，如果目录已被删除或不是文件夹，会提示原因并把它从最近列表中移除，而不是打开一个空窗口。

## 问题修复

- 子 Agent 模型弹窗：确认当前值后按回车会关闭并交还焦点；选到不同的模型时保持打开，方便点「立即重启」。
- 连续弹出的确认框不再继承上一个框的勾选状态。
- 在标签或编辑器组上右键时，菜单按**被右键的那个组**显示，而不是按当前活动编辑器；窄窗口下点击空白处也不会落到相邻组。
- 关闭 Webview 面板后会释放底层资源，不再随反复开关累积占用。
- Swarm 审核同时出现在多个分组时，折叠分组后不再残留空行。见 [Swarm 代码审核](doc:perforce/swarm-code-review)。

## 升级注意事项

- **多窗口默认开启**：拖出建窗默认可用；不需要时在设置里关闭 `workbench.editor.dragToOpenWindow`，跨窗口拖动不受影响。
- **推送目标固定**：Git 图谱的「同步并推送 main」固定推送 `main` 到 `origin`，与本次同步选择的目标分支无关；如果勾选了检出 `main` 的主工作树，它会先被重置，随后推送的是重置后的 `main`。
- 本次没有需要手动迁移的破坏性变化。
