## 本次重点

上一个版本让编辑器可以拆成多个窗口，这个版本把「开在哪」也交给你：在几乎所有能打开文件、页面或会话的地方，`Enter` 开在当前编辑器组，`Ctrl+Enter`（macOS 为 `Cmd+Enter`）在旁边新开一屏，`Alt+Enter` 开在一个新的编辑器窗口；鼠标对应 `Ctrl+点击` / `Alt+点击`。多显示器时新窗口优先放到另一块屏幕并全屏显示。完整按键见[快捷键速查](doc:reference/keyboard-shortcuts)。

## 打开落点：当前组 / 侧分屏 / 新窗口

- **一套手势从头用到尾**：列表、树、右键菜单、链接、命令面板和各类按钮都认同一组操作。没有高亮条目、或条目本身不打开编辑器时，组合键与普通 `Enter` 表现一致。
- **选择器与列表**：快速打开（`Ctrl+P`）、快速搜索（`Ctrl+Q`）、工作区符号（`Ctrl+T`）、搜索结果、资源管理器、源代码管理、提交变更、时间线、Git / Perforce 图谱的「提交变更」、Agent 会话列表、Swarm 审核与文件、Session Changes。
- **右键菜单**：先悬停或用方向键高亮会打开编辑器的条目，再按 `Ctrl+Enter` / `Alt+Enter`，与在该条目上 `Ctrl+点击` / `Alt+点击` 等价。
- **链接、命令与按钮**：Markdown 预览、文档正文、Agent 消息里的文件链接，终端里的文件路径，工具调用卡片里的文件按钮；命令面板中会打开页面或文件的命令（行尾齿轮也支持）；状态栏、标题栏、菜单栏、通知按钮和发行说明里的入口。
- **打开的是副本还是移动**：文件在新窗口里打开的是**副本**，原标签页保留；Git / Perforce 图谱、设置、快捷键、帮助、发行说明、AI 设置这类**全局唯一**的页面是**移动**过去，不会多出一份；Agent 会话同样是移动，避免两个窗口同时对话同一个会话。
- **这些情况保持原样**：列表行上的 `Ctrl+点击` 仍是多选，要侧开请用键盘手势；`Ctrl+Tab`、`Alt+S` 这类「按住修饰键、松手即打开」的列表不适用；编辑器内部的 `Ctrl+Enter`（提交信息框、代码行内）仍是原义；Swarm 审核列表的「跳到 Swarm 更改」改用 `Ctrl+Shift+Enter`；Markdown 源码模式受编辑器底层限制，没有单独的 `Alt+点击` 新窗口手势，需要新窗口时在预览里操作。

## 搜索与导航

- **空格预览搜索结果**：在结果行按 `Space` 会以预览标签打开对应文件并定位到匹配行，焦点仍留在结果列表，可以继续用方向键往下看；`Enter` 会固定标签并把焦点移到编辑器，鼠标单击不变。见[全局搜索](doc:search-navigation/global-search)。
- **按 `Ctrl+Shift+F` 回到上次结果**：从搜索结果跳到编辑器后再按一次，会回到刚才聚焦的那条结果，查询与结果都保持不变。
- **`Alt+C` 移除列表里的高亮项**：命令面板的最近使用、最近打开的项目、`Agents: 打开侧边任务…`、`Ctrl+Tab` 的标签行，行尾有 × 时都可以把高亮移到该行后按 `Alt+C`，与点 × 等价，列表不会关闭。`Ctrl+Tab` 刚打开时还按着 `Ctrl`，此时先按 `Enter` 解锁再按 `Alt+C`。见[快速打开](doc:search-navigation/quick-open)。
- **巨型工作区不再被后台扫描拖慢**：磁盘文件清单只在打开快速打开或点击时构建，全局排队并降权，限时 3 分钟 / 512 MB；工作区符号预热和 tsconfig 枚举不再拉起整棵目录树。终端里悬停看起来像路径的文本只检查文件是否存在，点击时才搜索，URL 尾段也不会再被误认成路径。`js/ts.prewarm.projects` 的路径补全只覆盖前 8 层目录且限时完成，超大项目可能只列出部分路径，手填完整路径同样有效。

## AI Agent

- **输入框撤销 / 重做**：焦点在输入框时，`Ctrl+Z` 撤销、`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做。刚插入的 `@` / `#` 引用（一次拖入多个文件算一步）与粘贴 / 拖入的图片都可以撤销，文本、引用、图片按操作先后依次撤销；用方向键召回历史输入并接受后，一次 `Ctrl+Z` 也能回到召回前的草稿。
- **发送到 Agent 聊天**：在资源管理器或 SCM 侧栏对文件 / 文件夹右键，选「发送到 Agent 聊天」，选中项会以 `@` 引用插入输入框；SCM 文件夹会展开为其下的所有文件。见[第一次对话](doc:ai-agent/first-session)。
- **侧边任务数量一眼可见**：会话标签页与会话列表项在有直接下级侧边任务时显示 `⑂ N`，没有时不显示；标题过长时优先省略标题，让数量始终看得见。
- **直接删除侧边任务**：`Agents: 打开侧边任务…` 的列表每行行尾有 ×，点它或把高亮移到该行按 `Alt+C` 即可删除；有下级时会一并删除并在确认框里告知数量，取消确认后该行留在列表里。见[管理会话](doc:ai-agent/managing-sessions)。

## Perforce

- **p4delta 最低版本升到 0.1.21，安装提示默认「确定」**：低于这个版本或读不出版本时会回退原生 p4，并提示升级或修改 `perforce.p4delta.path`；自动安装会继续把编辑器维护的副本升到最新。p4delta 安装 / 升级这类信息级提示的关闭按钮改为「确定」并默认聚焦，警告和错误保持「取消」。见[关于 p4delta 引擎](doc:perforce/resolve-and-advanced)。
- **超大范围拉取不再中途失败**：p4delta 拉取改为边收边记，逐文件记录不再全部堆在内存里，数十万文件的大范围拉取也能跑完。
- **「改动」分组只显示聚焦范围**：源代码管理的「改动（Changes）」分组现在只列出聚焦范围内的未签出文件（包括开启 `workspace.focusShowRootFiles` 时的根目录文件）。聚焦之外的文件被外部工具修改时不会出现在这个分组，但它在资源管理器或编辑器里的改动徽标照常显示。见[聚焦目录](doc:search-navigation/focus-folders)。
- **Swarm 后台读取更安静**：自动刷新、恢复会话等后台读取失败时只记日志，不再自动弹出 Output 面板；你主动刷新时仍照常提示。见[Swarm 代码审核](doc:perforce/swarm-code-review)。

## 多窗口

- **`Ctrl+W` 跟着当前聚焦窗口走**：用 `Alt+Tab` 切回主窗口后，`Ctrl+W`、保存、分屏、`Esc` 回到编辑器等针对「当前编辑器」的操作都作用于主窗口的活动标签，不会误关或误改辅助窗口里的标签。
- **打开文件落到最后使用的窗口**：在辅助窗口里编辑后回主窗口资源管理器打开文件（回车、快速打开、搜索结果、链接等同理），文件会在该辅助窗口里打开并把它带到前台；想改回主窗口，点一下主窗口的编辑区即可。
- **辅助窗口细节修正**：按 `Ctrl+Tab` 切回主窗口的某个后台标签后，光标会正确落在编辑器里；Peek References 也不再比主窗口大一号。见[标签页与分屏](doc:editing/tabs-and-split)。

## 其它改进

- **C++ 多行文档注释着色**：`/** ... */` 文档注释现在整段按注释着色，不再只有第一行。
- **Git 图谱同步结果改用通知**：工作树同步完成后在右下角用通知汇总结果，不再弹模态框；全部成功或仅有跳过时稍后自动收起，有工作树重置失败时警告常驻，可在通知中心回看。见 [Git 图谱](doc:git/git-graph)。

## 问题修复

- 删除 Agent 会话后，在途的会话列表扫描不再把它重新建回列表。
- 时间线右键菜单的「打开更改」不再静默无反应。
- Perforce 的 shelved 文件行从右键菜单打开时不再因参数错误失败。
- Markdown 的「查找文件引用」在扩展返回结果后能正常打开目标文件并显示引用。

## 升级注意事项

- **p4delta 门槛是 0.1.21**：旧版本会被拒绝并回退原生 p4——功能可用，但没有加速。升级方式：等待自动安装更新、运行 **Perforce: 安装或更新 p4delta**，或把 `perforce.p4delta.path` 指向新版本。
- **Swarm 审核列表的 `Ctrl+Enter` 改了含义**：原来它是「跳到 Swarm 更改」，现在改为「在右侧分屏打开审核」；「跳到 Swarm 更改」改用 `Ctrl+Shift+Enter`。
- **「改动」分组范围收窄**：开启聚焦目录后只显示聚焦范围内的改动。需要看别处的改动时，把对应目录加入聚焦或清空聚焦。
- **新窗口打开文件是副本、全局页面与会话是移动**：文件在新窗口里得到独立标签页，原标签页保留；单例页面和 Agent 会话是移动过去，原标签页关闭，避免同一对象出现两份。
