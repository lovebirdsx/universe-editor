## 本次重点

这个版本把 Agent 会话的时间线交给你决定：新会话默认只看**消息**，思考过程与普通工具卡收起；输入框下方动作行的下拉提供五档显示方式，`Ctrl+Alt+F` 也能循环切换。Markdown 预览同时加入 LaTeX 公式，行内 `$...$`、块级 `$$...$$` 和 `math` 代码块都能直接渲染。快速打开（`Ctrl+P`）输入关键词后，最近打开过的文件会单独排在顶部；扩展视图标题栏也新增「...」菜单，过滤与更新入口集中到一处。

## AI Agent

- **五种时间线显示方式**：点开输入框下方动作行右侧的下拉，可选「智能折叠 / 全部折叠 / 全部展开 / 隐藏思考 / 仅消息」，`Ctrl+Alt+F` 依次循环。新会话默认使用「仅消息」；想改默认档位，可在设置 `acp.defaultCollapseModes` 里按 Agent ID 指定。见[管理会话](doc:ai-agent/managing-sessions)。
- **「仅消息」保留全部回复**：你的消息和 Agent 的每一条文本回复都会显示，不再只留最后一条。子 Agent 卡片、错误消息、上下文压缩 / 恢复状态、计划确认卡，以及提问 / 等你决策的卡片始终保留；普通工具卡（包括失败的）隐藏。会话查找条只搜索当前显示出来的内容，被隐藏的卡片搜不到。
- **被隐藏的活动有尾部提示**：当 Agent 正在输出的内容恰好被当前显示方式隐藏时，时间线尾部会显示带旋转图标的提示：第一行是「正在思考…」或当前工具名，第二行是对应细节——思考首行、正在执行的命令、目标文件路径和已运行时长；失败时附简短原因。等待你确认权限或回答提问时不会显示；「隐藏思考」只显示「正在思考…」，不会露出思考正文。
- **侧边任务与分叉继承显示方式**：新建侧边任务或分叉时，会继承源会话当时的显示方式；之后父子各自切换互不影响，重新打开也各自保留。
- **Explore 子 Agent 报告可直达**：Explore 子 Agent 保存了调查报告时，发起它的卡片头部会多出「跳转到调查报告」和「打开调查报告」两个图标。跳转只滚动并高亮对应结果卡，不展开；打开会直接打开报告，`.md` 优先显示渲染预览。`Ctrl` / `Cmd` + 点击（或 `Ctrl+Enter`）在聊天右侧打开，`Alt` + 点击交给辅助窗口；报告卡不在当前时间线时两个图标都不显示。

## Markdown

- **支持 LaTeX 公式**：预览可用行内 `$...$`、块级 `$$...$$` 和 `math` 围栏代码块写公式，由内置 KaTeX 离线渲染，语法与 VSCode 一致。`$5 and $6` 这类货币写法不会被误判；公式放进表格时用 `\vert` 或 `\mid` 代替 `|`；写错时该公式以红色原文显示，不影响文档其它部分。设置 `markdown.math.enabled` 控制文件预览是否渲染（默认开启），`markdown.math.macros` 可定义全局自定义宏；聊天、文档中心等阅读界面始终渲染。见 [Markdown](doc:editing/markdown)。
- **路径链接查找更可靠**：Markdown 预览里的路径链接在直接匹配不到时，会先查最近打开的文件，再在工作区里实时查找；开启焦点模式时限定在焦点文件夹内。唯一命中直接打开，多处命中会打开选择列表，无法确认时提示「无法确认文件是否存在」，而不是误报「文件不存在」。每次点击都重新查找，所以刚新建并保存的文件也能立即打开。

## 搜索与导航

- **快速打开先列最近文件**：在 `Ctrl+P` 里输入关键词后，最近打开过且匹配的文件会先出现在顶部「最近打开」分组，其余匹配结果进入「其他结果」分组。最近分组的匹配更严格——输入不带 `/` 时只按文件名连续匹配，想按目录名找最近文件请把路径一起输入。见[快速打开](doc:search-navigation/quick-open)。

## 扩展

- **标题栏「...」菜单**：扩展视图标题栏右上角新增「...」菜单，可勾选「内置扩展」「可更新扩展」——勾选会把对应 token 写进搜索框，取消勾选即移除；「检查扩展更新」也移到了这里，「更新全部扩展」只在有可用更新时出现。搜索框输入 `@builtin` / `@updates` 的用法不变。见[扩展](doc:customization/extensions)。

## 多窗口

- **把编辑器移回主窗口**：在辅助窗口的标签上右键选「将编辑器移到主窗口」，或在标签栏空白处右键选「将编辑器组移到主窗口」，也可以在命令面板运行同名命令。目标组是主窗口最近使用且未锁定的编辑器组；移走最后一个编辑器时该辅助窗口会自动关闭，整组移走后空出来的编辑器组也会被移除。见[标签页与分屏](doc:editing/tabs-and-split)。
- **辅助窗口在另一块屏幕改为最大化**：多显示器下把编辑器开到一个新的编辑器窗口时，窗口改为在目标屏幕最大化显示，因此可以拖动标题栏移动（全屏窗口不响应拖动）。旧版本保存的全屏窗口位置会在下次恢复时自动转为最大化。

## Perforce

- **Swarm 审核可跨 stream 强制应用**：审核文件未映射到当前工作区（例如审核在另一个 stream / 分支）时，确认框会提供「强制应用」。它优先走 p4 原生的跨流 unshelve，服务器不支持时退化为替换 stream 前缀后写入文件内容；无法映射的文件会跳过并在结束后统一报告。全部文件都未映射时，确认框只有「强制应用」一个动作，默认焦点落在「取消」；审核版本没有记录 stream 信息时不提供强制应用。见[Swarm 代码审核](doc:perforce/swarm-code-review)。
- **只有 p4delta 能执行的拉取不再被扫描拦住**：新建工作区首次拉取，或范围里有 p4 写不出的排除项时，只要 p4delta 可用就直接交给它，不再等后台扫描先确认。两个引擎都接不了时，提示以「未执行拉取」开头并写明 p4 与 p4delta 各自的原因，不会悄悄扩大成整个工作区；p4delta 在本次会话被停用期间也会如实拒绝。见[同步与状态](doc:perforce/sync-and-status)。

## 问题修复

- 同时打开多个 Agent 会话、会话历史较长时，输入不再卡顿：会话改动改为按会话分片保存，每次只写入发生变化的会话。
- Git 图谱点「加载全部」后，提交计数不再残留「+」，后台刷新也不会再让「加载全部」按钮重新出现。
- 快速搜索（`Ctrl+Q`）对尚未打开的文件按回车后，光标会跳到匹配位置，不再停在文件开头。
- 在辅助窗口里打开快速输入（如 `Ctrl+P`、转到行）或对话框时，浮层出现在当前窗口，关闭后焦点回到正确的窗口；在命令面板里执行编辑器命令不再报「需要聚焦的编辑器」。
- 在大型工作区里按 `Ctrl+Shift+E` 切回资源管理器不再卡几秒：页面只渲染可见行，不再把整棵树一次性画出来。
- 设置中已删除的子项目根目录（`acp.projectRoots`）会被自动跳过，不再让 Agent 启动失败并为每个 Agent 弹一次通知。
- 取消或超时的 Perforce 操作会把 p4 / p4delta 进程及其子进程一并结束，不再在后台残留。

## 升级注意事项

- **新会话默认「仅消息」**：升级后新建的会话默认只显示文本消息，思考与普通工具卡不显示；已保存过显示方式的会话沿用原记录。想改默认可在设置 `acp.defaultCollapseModes` 里按 Agent 指定（例如 `{"claude-code":"default"}`），也可以随时用会话里的下拉或 `Ctrl+Alt+F` 切换。
- **远程开发协议升到 v15**：升级编辑器后重连一次，编辑器会自动停止旧 daemon、重传并启动新版本；若自动重部署失败或一直提示协议不匹配，运行 **Remote-SSH: 停止远程服务器** 后重新打开该主机的远程工作区。见[远程开发](doc:remote/overview)。
