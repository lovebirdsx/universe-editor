## 本次重点

新增**手机遥控**：把手机当作 PC 上 Agent 会话的遥控器——离开工位后可以看收件箱、审批、补一句话，甚至把会话分支的成果直接交付到 main。入口在命令面板的 **首选项: 打开手机设备设置**，手机与 PC 处于同一 Tailscale 网络或局域网即可。见[手机遥控](doc:ai-agent/mobile)。

## 手机遥控

- **开启与配对**：在设置页启动网关，用二维码或 8 位配对码配对新设备；默认只监听 `127.0.0.1`，通过 Tailscale Serve 或局域网自签 HTTPS 供手机访问。局域网模式首次使用需按提示核对证书指纹。
- **收件箱**：按待审批 / 运行中 / 出错 / 已完成分组，显示工作区「有修改」、远程会话与只读标记。点进会话可审批、回答提问、发送、停止、切换模式 / 模型，也能分叉、回退和打开侧边任务。
- **通知**：等待审批、Agent 提问、完成或出错时推送到手机，点击直达对应会话；可设置 PC 聚焦时也提醒。Web Push 需要 HTTPS，iOS 需先把页面添加到主屏幕。
- **草稿同步**：同一会话在 PC 与手机同时打开时，文字、光标与附件实时双向同步，发送后两端一起清空。
- **交付到 main**：有待交付内容的会话行会显示 **交付** 徽标，按确认页把会话分支的提交应用到 main 并推送，完成后同步其它 worktree；支持撤销与重试。也可长按会话选择 **推送分支**。
- **受信设备**：手机默认不能选「始终允许」或绕过权限；在 PC 设置页逐台勾选受信后，手机上的选项会实时刷新。

## AI Agent

- **删除会话**：命令面板 **Agents: 删除 Agent 会话**，或会话标签页 / 聊天区右键、会话列表垃圾桶图标。会连同侧边任务子树一起删除；确认框可在 `acp.sessions.confirmDelete` 重新打开。见[管理会话](doc:ai-agent/managing-sessions)。
- **回退与分叉入口更全**：新增 `/rewind`、`/fork` 斜杠命令，命令面板 **Agents: 回退 Agent 会话…** / **分叉 Agent 会话…**，快捷键 `Ctrl+Alt+Shift+Z` / `Ctrl+Alt+Shift+F`，以及会话列表与标签页右键。未指定消息时会先弹出消息选择器。
- **退出保护**：任意窗口还有运行中的会话时，退出会先弹确认框；只在发起退出的窗口弹一次，并列出其它窗口的会话数量与工作区。
- **焦点切换**：`Ctrl+Alt+I` 改为在输入框与时间线之间双向切换；想固定跳到某一侧，用命令面板的 **聚焦 Agent 输入框** / **聚焦 Agent 时间线**（默认无快捷键，可自行绑定）。
- **问答卡片默认展开**：提问与需要你决策的卡片不再默认折叠，问题与答案直接可见。
- **其它**：输入框 `/rename` 改名后同步会话标题；`Alt+S` 能列出重启后尚未恢复运行的会话；工作区外目录新建会话改为新窗口打开；切换会话时的首帧渲染开销降低；后台任务运行期间不再误显示「已停止」，也不会在停止后被后台任务悄悄唤醒。

## 编辑与导航

- **面包屑对齐 VSCode**：路径段、文件 / 符号下拉与完整大纲树，支持键盘导航与横向滚动。新增 `breadcrumbs.enabled`、`breadcrumbs.filePath`、`breadcrumbs.symbolPath`、`breadcrumbs.icons`、`breadcrumbs.symbolSortOrder` 配置。
- **查找文件引用**：TypeScript / JavaScript 文件可查找被哪些文件引用，快捷键 `Ctrl+K Ctrl+R`，也可从命令面板、标签页或资源管理器右键触发。见[符号与定义](doc:search-navigation/symbols-and-definitions)。
- **统一的列表导航**：`Ctrl+P` / `Ctrl+N` / `Ctrl+J` / `Ctrl+K` 在资源管理器、搜索结果、源代码管理、会话列表、快捷键编辑器与各类浮层里都能上下移动；只有获得焦点的树 / 列表才接管这些键。见[快捷键速查表](doc:reference/keyboard-shortcuts)。
- **跨窗口移动编辑器**：标签右键或命令面板新增 **将编辑器移到窗口…** / **复制到窗口…**（整组同理），可选择任意已打开窗口，光标与滚动位置一并带过去。见[标签页与分屏](doc:editing/tabs-and-split)。
- **侧栏视图跟随最后使用的窗口**：大纲、时间线、资源管理器高亮与 `@` / `@:` 符号选择会跟随最后操作过的编辑器窗口；点大纲条目会把对应窗口带到前台。见[大纲](doc:editing/outline)。
- **紧凑文件夹按需加载**：连续单目录链仍合并成一行，但折叠时不扫描；展开或刷新时才读取，减少大目录反复扫描。见[资源管理器](doc:editing/explorer-and-files)。

## 其它改进

- **子进程不再残留**：关闭窗口、主进程被强杀或 Agent 退出时，其进程树会被一并回收；后台定时清理失去连接的孤儿进程，关闭窗口后不再有残余的文件监听。
- **源代码管理**：在命令行执行 git 操作后自动刷新 SCM；修复多选文件操作只作用于一个文件的问题。
- **`--quit` 启动参数**：等价于 File → Exit，可让外部脚本正常退出已打开的编辑器。
- **细节修复**：树视图滚动后首次点击不再被拉回顶部；快速输入的回车不再被分隔符吞掉；文本编辑器 `Shift+F10` 可正常弹出右键菜单；打开文件对话框从当前文件目录开始；远程 Windows 下输入裸盘符不再被解析成 `C:\D`；拖动分隔条不再误触发文件拖拽；复制行后书签图标不再重复。
- **Windows 安装包**：修复从 Git Bash 打包时漏装文本搜索组件、导致安装版搜索不可用的问题。

## 问题修复

- 会话休眠后唤醒，回退不再报 Unknown messageId。
- 计划获批后恢复会话，不再退回计划模式。
- 修复失败后重试永远失败的问题。
- 手动固定 MCP 的会话新建侧边任务时，引用预填不再丢失。
- 在辅助窗口中使用搜索，结果会跳到匹配位置。
- 手机端：超长工具调用标题不再导致会话打不开；有可交付内容时才显示交付入口；左滑、弹层滚动与新建会话按钮的交互问题已修复。

## 升级注意事项

- **`Ctrl+Alt+I` 改为切换焦点**：以前它总是聚焦 Agent 输入框；现在焦点在输入框时会切到时间线。需要固定回输入框时，用命令面板的 **聚焦 Agent 输入框**，可在[自定义快捷键](doc:customization/keybindings)里绑定。
- **大纲树聚焦时 `Ctrl+K` 用于上移**：列表导航会先接管 `Ctrl+P` / `Ctrl+N` / `Ctrl+J` / `Ctrl+K`；焦点在筛选框或标题栏时 `Ctrl+K` 仍会开始组合键。
