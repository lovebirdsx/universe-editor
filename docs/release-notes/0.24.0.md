## 本次重点

Agent 现在可以**在没人盯着的时候自己开工**：新增的**触发器**支持定时、跑一条命令轮询、或每当 Swarm 出现轮到你处理的审核时启动一个会话，让它分析并把结论写成报告。触发器定义保存在工作区内的 `.universe-editor/triggers.json`，可以随仓库提交，团队共用同一份；入口是命令面板的 **触发器: 打开管理器**。

配合新增的**后台常驻**：开启「关闭窗口后保持后台运行」后，关闭窗口只是隐藏到系统托盘，会话与手机遥控继续可用。

- 触发器怎么配、怎么写结果 → [Agent 触发器](doc:ai-agent/triggers)
- 后台常驻、托盘与登录自启 → [手机遥控](doc:ai-agent/mobile)

## Agent 触发器

- **四种触发源**：手动、定时（cron / 固定间隔）、命令轮询（只在命令输出里出现新条目时触发，首次取数只建基线）、外部事件（目前内置 Swarm「轮到你审核」）。定时任务错过的槽位可选择直接跳过，或在下次启动后补跑最近一次。
- **触发器管理器**：命令面板 **触发器: 打开管理器**、Sessions 侧栏标题栏的 ⚡ 按钮，或状态栏的 ⚡ 条目打开。单例标签页，左侧按工作区分组，右侧是概览 / 配置 / 运行历史；搜索、状态筛选、折叠分组、选中项与滚动位置都会记住。
- **新建向导**：五步向导从触发源模板或 skill 模板起步，创建时直接写入所在工作区的配置。仓库附带四份可直接改造的 skill 骨架：Swarm 分诊、双周报、团队周报摘要、CI 失败自动修复。
- **防误开的闸门**：工作区里新出现的触发器在本机**默认暂停**，并且必须在本机**确认一次**才会生效。确认框会列出 Agent、模式、技能、提示词摘要、预算、并发、轮询命令与固定的 MCP 服务器，并提供「查看完整定义」；确认绑定整份定义，改任何字段（包括 `enabled` 与名称）都要重新确认。
- **无人值守下的保守权限**：自动化会话不套用你的个人自动放行，「始终允许」不会出现，计划一律等人工确认；唯一自动允许的是写入本次运行目录。高权限模式会在确认框里额外警告，事件源 + 高权限时警告更强。
- **结果与通知**：Agent 把结论写进运行目录的 `result.json`（`info` 表示无需关注，`escalate` 表示需要你处理），后者会发「需要你处理」通知。每次运行都是一个普通会话：Sessions 列表带 ⚡ 徽标、判决标签与「来源」筛选，右键可打开只读的运行报告标签页。
- **运行观察与兜底**：状态栏 ⚡ 常驻入口，有需要处理的问题时显示 `⚡ N`；运行历史保留最近 100 条并可按结果筛选；失败从 1 分钟起指数退避，连续失败 5 次自动暂停并通知；日志在输出面板的 Triggers 通道。每次运行独立计预算（默认单次 1 美元、活跃时间 30 分钟、单张审批卡等待 24 小时，`maxCostUsd` 写 `null` 表示不限费用），全局并发默认 2，可在设置的 `triggers.maxConcurrentRuns` 调整。
- **远程工作区也能用**：配置仍是远端工作区的 `triggers.json`，轮询命令与 Agent 会话在远端执行。需要保持该窗口打开且连接正常，断连时定时任务按「错过」策略处理、手动运行提示「远程未连接」、运行报告暂不可读。

## 后台常驻与托盘

- **关闭窗口后保持后台运行**（手机设备设置里开启）：关闭窗口只是隐藏到系统托盘，网关与 Agent 会话继续运行，手机仍可遥控；没有会话活动的隐藏窗口空闲 10 分钟后自动关闭。首次隐藏会给一次提示，说明会话仍在运行。
- **托盘菜单**：显示各个已隐藏的窗口、查看手机网关状态、真正退出；新版本已下载完成且当前没有可见窗口时，还会出现 **重启以安装更新**，走正常的退出确认。
- **登录时在后台启动**（仅安装版 Windows / macOS）：登录系统后无窗口启动，需同时开启网关与后台常驻；关掉其中任一开关就会取消登录项。
- 后台模式下，从手机新建会话会在后台打开窗口，不会把编辑器弹到 PC 屏幕上。

## 手机遥控

- **`@` 文件与 `#` 上下文**：手机上可以直接引用当前工作区的文件、符号、本地修改、已打开的编辑器、文档、Git 提交与扩展上下文，插入的是结构化引用而不是一段普通文字。
- **输入框快捷插入**：输入框为空时点左侧按钮，面板顶部可在 `/ 指令`、`@ 文件`、`# 上下文` 之间切换；切换时开头的符号原地替换，已输入的关键词与光标位置都保留。
- **斜杠指令按最近发送排序**：执行过的指令排到最前，从未发送过的保持 Agent 原有顺序（记录只存在这条手机上）。
- **图片与复制**：输入框可以粘贴剪贴板里的图片；消息可以复制原文，或整条渲染成一张带留白的图片。
- **新建会话**：可以选择工程子目录、从项目根快捷进入，并沿用上一次的目录（与 PC 共用同一份记忆）。
- **会话页**：子模型与 MCP 服务器的启停都能在手机上改；顶部新增上下文用量圆环，接近上限时变红，点按可在百分比与 token 数之间切换。子 Agent 卡片在「仅消息」显示方式下会显示它最新的一次调用，计划卡片展开后限高并支持内部滚动。
- **交付与报告**：交付改为后台执行，能看到进度且不再独占界面，同一工作区只有代表会话显示交付徽标；手机也可以直接查看触发器的运行报告。

## 编辑器与快捷键

- **列表横向导航**：树视图、搜索结果、源代码管理、大纲、扩展视图的分区列表与 Agent 配置栏支持 `Ctrl+H` / `Ctrl+L`，与 `←` / `→` 等价。
- **`Ctrl+P` / `Ctrl+N` 不再是菜单别名**：无论菜单、浮层是否打开、列表是否聚焦，它们始终是「转到文件」/「新建文件」；上下移动统一使用 `Ctrl+K` / `Ctrl+J`。
- **没有打开编辑器时 `Esc` 也能回到编辑区**：焦点在侧栏列表或树时先按 `Esc`，就能正常开始 `Ctrl+K` 和弦。
- 设置页的目录高亮跟随实际滚动位置，点了靠下的分类不会再高亮到更靠前的分类。大纲的方向别名也收敛为 `Ctrl+K` / `Ctrl+J` / `Ctrl+H` / `Ctrl+L`，详见[快捷键速查表](doc:reference/keyboard-shortcuts)与[大纲](doc:editing/outline)。

## 远程开发

- 远端服务换代（升级或崩溃重启）后客户端自动重连；远端终端会提示连接断开，恢复后自动在远端重启并保留原有输出，远端扩展宿主同样自动重启。详见[远程开发](doc:remote/overview)。
- 修复同一远程连接里多个文件监听互相覆盖、导致部分变更不刷新的问题。

## 问题修复

- 关闭窗口后主进程不再残留，同时修掉退出时的资源泄漏。
- 异常退出取证会记录主进程退出码，帮助区分正常退出、被外部结束与原生崩溃；你在集成终端里自己启动的后台进程占用内存过高时，也不会再被当成编辑器的 OOM 报警（仍记录到诊断日志）。
- 磁盘根目录（如 `D:\`）右键「打开」不再被当成文件。
- 交付：推送验证失败不再误报为交付失败；手机端能识别命令行交付持有的锁，不会并行发起第二次交付。
- 手机端：会话结束后不再残留流式光标；手机与 PC 之间删除草稿附件会同步；在手机上切换 MCP 导致的会话重启后，手机会自动跟随新会话，不再提示已关闭。
- Claude Agent 更新：上下文压缩之后，从压缩边界之前的消息分叉 / 回退可以正确定位。

## 升级注意事项

- **手机权限放开**：手机端不再需要「受信设备」，也不再逐台确认高风险操作——手机与 PC 权限完全一致，可以直接切换到绕过权限 / 完全访问，审批卡上也能提交「始终允许」。PC 上的「允许高风险操作」开关与相关确认已删除。请只在自己的设备上配对，并为手机设置锁屏；刷新手机页面即生效。
- **`Ctrl+P` / `Ctrl+N` 不再是列表与菜单别名**：以前在菜单、`Ctrl+Tab`、树视图与大纲里它们与 `↑` / `↓` 等价，现在任何表面都是「转到文件」/「新建文件」。上下移动请改用 `Ctrl+K` / `Ctrl+J`。
- **`Ctrl+H` / `Ctrl+L` 接管横向导航**：在支持 `←` / `→` 的树视图、扩展视图分区列表与 Agent 配置栏聚焦时，它们从「替换」/「在编辑器中展开行选择」变为折叠、展开；在编辑器与输入框里仍是原来的功能。
- **大纲别名变更**：`Ctrl+B` / `Ctrl+F` 不再左右移动，改用 `Ctrl+H` / `Ctrl+L`；`Ctrl+P` / `Ctrl+N` 在大纲里也恢复全局含义。
- **触发器默认不开工**：新出现的触发器在本机默认暂停，未确认前连「立即运行」也会被拒绝；确认绑定整份定义，改任何字段都要重新确认。轮询命令以你的账号权限在工作区所在主机上执行，只轮询你信任的脚本。
- **未写预算时的默认值**：单次运行费用上限 1 美元、活跃时间 30 分钟、单张审批卡等待 24 小时。需要更长请显式调大，或把 `maxCostUsd` 写成 `null` 表示不限费用。
- **后台常驻默认关闭**：只有手动开启「关闭窗口后保持后台运行」后，关闭窗口才会隐藏到托盘；开启后要真正退出请用托盘菜单的「退出」。
