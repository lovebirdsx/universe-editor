## 本次重点

这个版本最重要的是**全局 Vim 模式**：开启后，Vim 键位不再只作用于编辑器文本，而是覆盖资源管理器、搜索结果、菜单、标签栏、设置页、通知中心、Chat 时间线、Markdown 预览与终端。命令面板搜索 **Vim** 执行「切换 Vim 模式」、把 `vim.enabled` 设为 `true`，或点击状态栏的模式条目即可开启；默认关闭，关闭后 Vim 不再接管任何按键。完整键位与快速上手见 [全局 Vim 模式](doc:reference/editor-shortcuts)。

## 全局 Vim 模式（可选，默认关闭）

- **覆盖范围**：编辑器文本（Normal / Insert 与三种 Visual）、列表与树、菜单与浮层、编辑器标签栏、ActivityBar、设置页、通知中心、Chat 时间线、Markdown 预览与文档中心，以及终端的 Normal Mode。它不依赖扩展，也不修改 Monaco 的原生键位。
- **编辑器内核**：`h/j/k/l`、`w/b/e`、`gg/G`、`f/t`、`%`、`Ctrl+F/B/D/U`、`zt/zz/zb`、`H/M/L` 移动；`d/c/y` 配文本对象（`ciw`、`ci"`、`da(`、`yip`…）、寄存器、`.` 重复与 Visual 编辑；折叠 `zc/zo/za/zM/zR/zj/zk/[z/]z`；搜索 `/ ? n N` 支持计数、smartcase 与可选高亮；代码导航 `gd/gD/gy/gi/gr/gR/K/*/#/]d/[d/]c/[c`。
- **列表与菜单**：列表、树与标签栏用 `j/k/h/l` 移动、`gg/G` 跳首末、`Enter` 或 `o` 激活、`x` 关闭标签、`m` 打开右键菜单；菜单、浮层、选择器、对话框与 Agent 配置栏仍支持 `Ctrl+J/K/H/L`。模式按界面记忆，不同分屏互不影响。
- **leader 与提示**：默认 leader 是 `Space`（如 `Space e` 资源管理器、`Space f` 快速打开、`Space p` 命令面板、`Space ?` 键位速查）；多键序列停顿约 0.3 秒会弹出 which-key 提示。状态栏显示当前模式与已输入但未完成的按键，按下没有映射的键会短暂提示 `Unsupported: <键>`。
- **终端 Normal Mode**：终端默认仍是 Insert（按键交给 shell），按 `Ctrl+Shift+\` 进入 Normal，可滚动、选择与复制；退出后继续输入。
- **中文输入法与自定义**：Windows 上 `vim.autoSwitchInputMethod`（默认开）会在 Normal 切英文、Insert 恢复；`vim.surfaces.*` 可按界面关闭，`vim.keymap` 可覆盖或新增映射，`vim.useSystemClipboard`、`vim.highlightSearch`、`vim.passThroughUnmappedKeys`、`vim.sequenceTimeoutMs` 等可调行为。

## 扩展：受信视图

- **扩展可以把原生界面挂进编辑器**：新贡献点允许扩展声明侧栏视图或编辑器标签页，运行时加载扩展提供的浏览器 ESM 组件，与编辑器共享同一套 React 实例；扩展 API 升至 0.25.0。详见 [扩展](doc:customization/extensions) 的「受信视图」一节。
- **默认不加载，先信任再启用**：这类界面与编辑器自身运行在同一环境，只有扩展被列入用户级设置 `extensions.trustedViewExtensions` 才启用；第一次遇到时会通知一次，点「信任并加载」即可。工作区设置不能替你同意。

## 触发器

- **运行报告入口更多**：自动化会话聊天区右上角的 ⚡ 查看报告按钮、会话标签页标题栏、Sessions 列表的 ⚡ 徽标、右键菜单，以及命令面板「触发器: 查看触发器运行报告」都能打开同一份报告。详见 [Agent 触发器](doc:ai-agent/triggers)。
- **报告可以用键盘阅读**：`j/k`、`d/u`、`Space`、`gg/G`、`Ctrl+F` 查找、`f/F` 链接提示、`?` 帮助；摘要条上 `o` 打开会话、`r` 刷新、`R` 重新运行。
- **重新运行历史运行**：历史行与报告页的「重新运行」会用该次运行保存的输入、按当前配置（含最新 skill）再跑一次，作为新的手动运行记录，便于反复验证 skill 调整；旧记录没有保存输入时会给出提示。
- **poll 触发器手动运行可选条目**：立即运行会先执行一次取数，让你选择一条作为事件数据；选中的条目记为已处理，下一轮自动轮询不会再触发它。预览取数失败只提示，不计入失败与退避。

## Agent 与手机

- **图片附件更多、更省**：PC 端单条消息默认最多 20 张图片（设置项 `acp.prompt.image.maxCount` 可调到 50）；手机端最多 20 张图片、一次最多 28 个附件（20 张图片 + 8 个文件）。发送前都会把长边压到 1568px 以内。详见 [第一次对话](doc:ai-agent/first-session) 与 [手机遥控](doc:ai-agent/mobile)。
- **PC 端消息可复制为图片**：在消息卡片右键选择「复制为图片」，会把正文、代码块、图片与附件渲染成 PNG 写入剪贴板；折叠的卡片会先临时展开、截完恢复。消息过长时会提示改用「复制消息」。
- **切到时间线更方便阅读**：时间线停在最底部时，`Ctrl+Alt+I` 会顺带把最后一条消息的顶部对齐到视口，从头阅读最新回复。
- **子 Agent 活动行更稳定**：「仅消息」显示方式下，运行中的子 Agent 活动行会常驻并固定高度，不会因消息暂时为空或步骤切换而抖动；最近一步是普通文本时会回溯到上一个思考 / 工具。

## 编辑器与文件

- **文件树固定父级行**：资源管理器、源代码管理分组、提交变更与会话更改的文件树在滚动时把当前层级的父文件夹钉在顶部（最多 5 行），点击可跳回；「在资源管理器中定位当前文件」也会把目标滚到视口中间。详见 [资源管理器与文件操作](doc:editing/explorer-and-files) 的「滚动时固定的父文件夹」一节。
- **速览引用树支持裸 `j/k/h/l`**：不用按 `Ctrl`，也不用开启 Vim 模式，就能在「查找引用」等速览里上下移动、折叠展开；`Esc` 仍是关闭整个速览。
- **对比编辑器可跳差异**：`Alt+PageDown` / `Alt+PageUp` 在对比编辑器里跳到下一处 / 上一处差异；Vim 模式下也可以用 `]c` / `[c`。
- **非 Git 仓库更清爽**：不是 Git 仓库的窗口不再在命令面板里显示 Git 命令，`Ctrl+Alt+G` 等快捷键也不会误触发。

## 问题修复

- 关闭快速选择、通知中心等浮层后，焦点会回到打开前的编辑区或列表；标题栏下拉与辅助窗口里的内联速览也能用 `Esc` 正常关闭。
- 取消输入法组合后，文件不再被误标为已修改。
- 设置页点击目录条目后，高亮会跟随实际位置，不再跳回上方的分类。
- 自动化会话关闭标签页时不再自动打开后台会话；后台探测与连接握手不再弹出 Preparing 通知；提问 / 决策卡片的折叠状态在切换编辑器后保持。
- 多个窗口同时打开时，扩展与 Agent 进程的输出不再广播给所有窗口；TypeScript 扩展扫描项目的请求也大幅减少，多窗口启动更顺畅。

## 升级注意事项

- **Vim 默认关闭**：不开启时 Vim 不会接管按键；本版对 `Ctrl+J/K/H/L` 与速览引用树的调整不受这个开关影响（见下面两条）。开启后，编辑器 Normal 模式下 `Ctrl+V`、`Ctrl+R`、`Ctrl+F/B/D/U`、`Ctrl+E/Y`、`Ctrl+O/I` 等会归 Vim，列表、菜单、浮层与终端里未映射的可打印键会被吞掉并提示；你自己的同键快捷键优先（保留键除外），也可用 `vim.surfaces.*` 只对某类界面关闭。
- **`Ctrl+J/K/H/L` 不再是纯列表 / 树的移动别名**：0.24.0 里它们在资源管理器、搜索结果、源代码管理、大纲、Agent 会话列表、快捷键编辑器、Git / Perforce 图谱等界面上与方向键等价，现在这些界面不再接管它们，`Ctrl+K` 和弦可以直接开始。列表内移动请用方向键，或开启 Vim 后用 `j/k/h/l`；菜单、浮层、选择器、对话框与 Agent 配置栏仍保留方向别名。
- **速览引用树改为裸键**：以前用 `Ctrl+J/K/H/L` 移动，现在直接用 `j/k/h/l`（不需要开启 Vim）；`Ctrl+J/K/H/L` 在这些界面恢复全局含义。
- **图片附件默认上限变化**：单条消息默认最多 20 张图片（原 5 张），单张仍不超过 5 MB；手机端一次最多 28 个附件，总大小不超过 50 MB。
- **受信视图需要手动信任**：扩展提供的原生界面默认不加载；请在用户设置 `extensions.trustedViewExtensions` 里列出扩展，或在首次通知里点「信任并加载」。工作区设置不生效。
