## 新建会话的连接中状态

点「新建会话」后，会话行**立即出现在列表最上方**，行内显示一个转圈的**连接中**标记——此时 Agent 进程正在后台启动和握手（可能花上几秒钟），你可以直接点击这行打开会话、输入内容，输入会在连接就绪后自动发出。

- 连接就绪后，连接中标记消失，该行变成一个普通会话行（位置不变）。
- 如果启动失败（例如未登录、Agent 进程起不来），该行会保留在列表里并显示**失败**标记，你可以点进去看具体错误，或直接删除它。
- 连接中的会话按状态过滤时归入**进行中**。
- 注意：只有握手成功的会话才会写入历史——重启编辑器后，从未成功启动的会话不会保留。

## 恢复历史会话

- 快捷键：`Ctrl+Shift+H`（恢复 Agent 会话…）。
- 从列表里挑一个（显示标题、所在目录、相对时间）。
- 属于**其它工作区**的会话，会以**只读预览**方式打开，避免误连到错误的目录。

## 刷新与切换

- **刷新列表**：命令"刷新 Agent 会话列表"。
- **跨窗口切换会话**：`Alt+S`（切换会话…）。标题栏中部的会话药丸常驻显示**所有窗口合计**的正在运行会话数（黄色表示有会话在等待输入），点击它等价于按 `Alt+S`。

## 过滤与排序

会话列表工具栏上的**漏斗**按钮会弹出过滤菜单（勾选项即为"显示"），当有任意非默认选项时按钮会高亮：

- **排序**：按创建时间 / 按更新时间（单选，默认按更新时间）。
- **按 Agent 过滤**：勾选要显示的 Agent（如 Claude Code、Codex）。
- **按状态过滤**：进行中、需要输入、失败、已完成——取消勾选即隐藏该状态的会话。
- **已归档**：勾选后显示已归档的会话（默认隐藏），详见[归档与置顶](#归档与置顶)。
- **Reset**：一键恢复全部默认。

过滤与排序的选择会被记住，跨工作区通用。它与工具栏的**搜索**框互相独立：输入搜索关键字时，结果按匹配度排序（此时忽略上面的排序设置）。

## 归档与置顶

会话越攒越多时，可以用**归档**把暂时不看的会话收起来，用**置顶**把重要会话钉在列表最上方。

### 归档会话

把鼠标悬停到某一行，点**归档**图标（或按 `Del`；也可以右键 → **归档会话**）。归档后：

- 该会话**默认从列表隐藏**——想看到它，打开过滤菜单勾选**已归档**，此时归档会话集中显示在列表最底部、文字置灰。
- 归档只是列表层的标记：**会话本体不受影响**——正在运行的会话不会被中断，已打开的会话标签页也不会关闭，随时可以正常继续使用。
- 恢复：对已归档会话点**取消归档**图标（或按 `Shift+Del`；或右键 → **取消归档会话**）。

### 置顶会话

把鼠标悬停到某一行，点**图钉**图标（或右键 → **置顶会话**）。置顶后该行始终排在列表最上方，并显示一枚常驻图钉角标；再次点击（或右键 → **取消置顶会话**）即可取消。

置顶会话同时**免于历史淘汰**：本地历史最多保留最近 100 条会话，超出时优先淘汰未置顶的旧会话。

> 归档 / 置顶状态保存在当前工作区，重启编辑器后保留；搜索框输入关键字时结果按匹配度排序，置顶不插队。

## 清除会话历史

- 命令："清除 Agent 会话历史"，会有确认弹窗。
- 它**只清除本地的历史索引**；Agent 侧保存的对话仍然保留，直到 Agent 自己清理。

## 会话可见范围

会话列表显示哪些会话可以配置——通过设置项 `acp.sessions.historyScope`，可选：

- 当前工作区（`workspace`）
- 当前工作树（`worktree`）
- 全部（`all`）

## 中断自动恢复

会话运行到一半，有时会碰上意外中断——供应商临时限流（如 429、"过载"）、Agent 进程崩溃或内部报错、或长时间卡住没有任何输出。**这些情况编辑器会自动尝试恢复，不需要你手动重启会话再重发指令。**

- **输入框上方的状态条**：正在恢复时，会在输入框上方出现一条不打扰的提示，显示当前在做什么、下一次自动尝试的倒计时和第几次尝试（如"连接已断开，N 秒后重连…（1/3）"）。
- **不打断你的工作**：恢复期间你**照样可以继续打字**——发出的指令会排队，等会话恢复后自动依次发出，和刚建立连接时的排队行为一致。
- **两类恢复**：
  - 临时性错误（限流、过载、服务端临时故障）：按递增的间隔**自动重试**当前这一轮，最多 3 次。
  - 连接断开或 Agent 内部崩溃（Agent 进程崩溃、运行中报错、卡住）：在后台**热重连**并恢复被打断的那一轮——不重放历史，上下文照旧。若这轮已经产出了部分内容，会以"继续"衔接，避免重复。若中断时正有一张待回答的提问或待批准的权限卡片（如计划模式下的提问），恢复时会改发一条带说明的衔接消息，告知 Agent 该提问是被中断取消的、而非你已跳过——Agent 会重新向你提问，不会当作你已回答或拒绝。
- **自动补发的"继续"**：这条由恢复机制自动发出的消息会显示为弱化样式并带 **自动重试** 徽标，与你手动发送的消息区分开；它不提供回退/分叉入口。
- **压缩被打断**：如果中断发生在压缩上下文的过程中，重连后重新开始的压缩会**合并进原来那张卡片**（计时重置），不会出现两张"正在压缩"卡片。
- **取消**：不想等自动恢复时，点状态条上的 **✕** 取消。
- **手动重试**：自动尝试用尽后，状态条会提示"自动恢复失败"，并给出 **Retry** 按钮，点它再试一次。
- **卡住判定**：一轮正在进行、但超过一段时间**没有任何输出**，会被判定为卡死，进而触发上面的热重连。这个阈值由设置项 `acp.turnStallTimeoutMs` 控制（毫秒，默认 `600000`，即 10 分钟）；设为 `0` 可关闭该看门狗。Agent 正在等你回答提问（AskUserQuestion 卡片）或批准权限时，这段时间的安静是正常等待，不会触发卡住判定。

> 只有**正在进行中的那一轮**被中断时才会触发恢复；空闲会话的连接断开不会在后台反复重连，下次发指令时会自动重新握手。

## 会话标题

会话标题会自动生成（先取首条消息，随后由 AI 生成更贴切的标题）。你也可以为它单独指定一个"会话标题模型"，详见 [模型选择与花费](./models-and-cost.md)。

### 手动重命名

想固定一个自己的名字时，可以手动重命名。入口（任选其一）：

- **命令面板**：`Rename Agent Session…`（重命名 Agent 会话…），作用于当前会话。
- **会话列表**：把鼠标悬停到某一行，点铅笔图标（可重命名任意历史会话）。
- **会话标签页**：在编辑器里打开的会话标签页上右键 → 重命名。

弹出的输入框会预填当前标题，回车确认、`Esc` 取消。手动标题的优先级**高于自动标题**：它不会被 AI 重新生成或 Agent 侧的自动摘要覆盖，并会同步到 Agent，从而在 `/compact` 与重启后依然保留。

> 属于**其它工作区**的会话（列表中带分支图标）不提供重命名入口——它们的标题由所属工作区维护。

### 会话列表右键菜单

在会话列表中对任意一行**右键**，会弹出该行的操作菜单：

- **置顶会话 / 取消置顶会话**：等同于图钉图标，见[归档与置顶](#归档与置顶)。
- **归档会话 / 取消归档会话**：等同于归档图标，见[归档与置顶](#归档与置顶)。
- **重命名会话**：等同于铅笔图标（属于其它工作区的会话不显示此项）。
- **打开会话位置**：在系统文件管理器中定位该会话的转录文件（Claude Code 为 `~/.claude/projects/…` 下的 `.jsonl`）。正在运行的会话会按需向 Agent 查询转录路径，无需等待列表刷新。仅当 Agent 没有对应转录文件时该项才置灰。在编辑器里打开的会话标签页或聊天区域上右键也有同样入口。
- **删除会话**：等同于垃圾桶图标，会先弹确认框（除非你此前勾选过"不再询问"）。


## 消息区右键拷贝

在会话时间线的消息内容上**右键**，菜单会按你点中的内容追加对应的拷贝项：

- 点中**图片**：**复制图片**，把图片拷进系统剪贴板。
- 点中**文件 / 资源链接**：**复制路径**，复制该资源的本地路径。
- 点中**选区上下文 chip**（消息顶部的 `文件:行号` 附件）：**复制文本**，复制 chip 里的选区文本快照。

这些项只在点中对应内容时出现；点中普通文本时，菜单仍是原来的复制 / 复制消息等项。
## 回退与分叉

把鼠标悬停到某条**你发的消息**上，右上角会浮现两个按钮，让你从对话中途改变方向。是否显示取决于当前 Agent 的能力：

| 按钮 | 作用 | 可用范围 |
| --- | --- | --- |
| 回退到此处（↩ 图标） | 把对话**截断**回这条消息，可选择是否把 Agent 期间改动的文件**回滚**到当时的磁盘状态，然后把这条消息的文本**回填**到输入框，方便你修改后重发（edit-and-retry）。 | Claude Code、Codex |
| 从此处分叉（分支图标） | 以这条消息**之前**的历史为起点，新建一个**独立会话**；原会话保持不变。 | Agent 需声明支持分叉 |

当 Agent 回答完毕（会话空闲）时，**时间线最末尾**也会出现一个「从此处分叉」入口：它以**完整对话**（包含最后一轮回答）为起点分叉——适合"保留这轮成果、换个方向再试"的场景，与悬停消息上的分叉（排除该消息及其后内容）互补。命令面板中的 **分叉 Agent 会话** 命令效果相同（对当前会话从末尾分叉）。回合进行中该入口隐藏，避免分叉到半截输出。

- **回退是破坏性操作**：截断后的对话无法恢复，因此会先弹确认框，并预览将回滚的文件数量（`+新增 / -删除` 行数）。
- 当这次回退**有文件改动**时，确认框提供三个选择：
  - **撤销修改并回退**：截断对话 + 把文件回滚到该点的磁盘状态。
  - **保留修改并回退**：只截断对话，**保留**当前的文件改动不动。
  - **取消**：什么都不做。
- 当**没有文件改动**时，直接显示单个「回退」确认按钮。
- 若 Agent 报告无法回退到该点，会给出提示且不做任何改动。
- 分叉后会自动打开（编辑器模式下新开标签页，侧栏模式下切到新会话）。属于**其它工作区**的会话需先在其所属工作树中打开，才能分叉。
- **不同 Agent 的回退实现略有差异**：Claude Code 由 Agent 自身回滚文件；Codex 的文件回滚由编辑器基于会话内的改动追踪完成（因此仅能恢复本次会话中 Agent 改过的文件）。两者的交互与确认流程一致。

## 侧边任务

聊天中划选一段文本后**右键** → **在侧边聊天中提问**，会以当前会话的完整上下文分叉出一个独立的**侧边聊天**，在编辑器区域右侧分屏打开——适合"针对这段内容追问几句"而不想打断主对话方向的场景。

- **干净的新聊天**：侧边聊天**不显示**主会话的历史记录（历史只作为 Agent 的上下文），重新打开也一样——只保留侧边聊天**自己**的对话，主会话的基线永不回放。打开后输入框已预填你划选内容的引用块，编辑后直接发送即可。首轮发送后标题由 AI 自动生成。
- **知道自己的角色**：首轮发送时会在后台附带一条你看不见的角色提示，让 Agent 明白自己是"被拉到一边追问"的侧边聊天——它会聚焦回答你划选的那段内容，而不会接着主会话的任务往下做，也不会主动提起这个身份。
- **只读约束**：侧边聊天默认以只读方式运行（Claude Code 为 Don't Ask 模式、Codex 为只读模式），只做解释、查询和轻量分析，不改动文件；你可以自行切换模式解除约束。
- **父子关系**：侧边任务**隶属于**它所属的会话，**不会出现**在会话列表里。主会话聊天区**右上角**会悬浮 **侧边任务 (N)** 按钮，点开可看到该会话的所有侧边任务，点击即在右侧分屏打开（未恢复的会自动恢复）。
- **视觉区分**：侧边聊天的标签页按「厂商图标 + 分支图标 + 会话标题」排列（悬浮提示标注"侧边任务"），聊天区右上角显示「已选文本片段」引用 chip（悬浮可预览划选原文），输入框描边也会高亮；空会话时不显示新会话引导面板，保持干净的提问画布——这些都便于与普通会话区分。
- 一个会话可以创建**多个**侧边任务；侧边任务里也可以再划选创建下一级侧边任务。
- 需要 Agent 支持分叉能力（Claude Code、Codex 均支持）；属于**其它工作区**的只读会话不提供该入口。

## 时间线导航

会话聊天记录称为"时间线"。以下按键**仅在聊天获得焦点时**生效：

| 操作 | 快捷键 | 命令标题 |
| --- | --- | --- |
| 上一项 / 下一项 | `Alt+↑` `Alt+↓`（或 `Alt+K` `Alt+J`） | 聚焦上一个 / 下一个时间线项（首条用户消息与顶部常驻的计划卡片也在序列内） |
| 顶部 / 底部项 | `Alt+A` / `Alt+E` | 聚焦时间线顶部项 / 底部项 |
| 滚动 上 / 下 | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | 向上 / 向下滚动时间线 |
| 翻页 上 / 下 | `Ctrl+Alt+PageUp` / `Ctrl+Alt+PageDown` | 时间线向上 / 向下翻页 |
| 折叠当前项 | `Alt+F` | 切换时间线项折叠状态 |
| 全部折叠循环 | `Ctrl+Alt+F` | 循环切换时间线折叠状态（全部） |
| 跳转到计划 | `Alt+P` | 聚焦顶部常驻的计划卡片（无计划卡片时跳转到最近的 ExitPlanMode 卡片） |
| 取消当前回合 | `Esc`（回合运行中；查找条或建议面板打开时会先关闭它们） | 取消 Agent 回合 |

## 会话书签

和[编辑器里的编号书签](../editing/bookmarks.md)一样，你也可以给会话时间线里的某一项（消息、工具调用卡片）打上 0–9 的编号书签，之后一键跳回。**每个会话各有自己独立的一套 0–9 十个槽**——在不同会话里用同一个编号互不干扰，跳转也只在当前会话内进行。

- **打上 / 清除**：把某个时间线项设为当前项（点击它，或用 `Alt+↑` `Alt+↓` 移动到它），按 `Ctrl+Shift+<数字>`。同一项上再按一次相同组合键即清除。
- **跳转**：按 `Ctrl+<数字>` 跳到**当前会话**里对应编号的书签。
- **视觉标记**：打了书签的卡片左缘会显示一个带数字的小徽标。
- **列出 / 清空**：命令面板运行 “List Session Bookmarks” 列出**当前会话**的全部书签（选中即跳转），“Clear All Session Bookmarks” 一次清空**当前会话**的书签。

> 注意：这些快捷键与命令**仅在会话编辑器获得焦点时**生效——此时它们优先于全局的 `Ctrl+0`（重置缩放）等绑定；焦点不在会话里时，数字键仍归各自的全局操作。会话书签持久保存在当前工作区；由于消息的内部标识在会话「恢复」后可能变化，指向已恢复消息的书签若失效会被静默丢弃。

## 在会话中查找

- `Ctrl+F` 打开查找条（在会话中查找）。
- `F3` 下一个匹配项 / `Shift+F3` 上一个匹配项 / `Esc` 关闭。
