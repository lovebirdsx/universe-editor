# 手机遥控（手机设备）

把手机当作 PC 编辑器里 Agent 会话的遥控器：离开工位后，可以在手机上查看正在等待的事情、做一次审批，或者补一句话。会话、Agent 进程和工作区始终留在 PC 上，PC 关闭时手机显示离线。

> 当前版本（M8）补齐了历史会话目录：可以在手机的「会话」页搜索并重新打开 PC 已打开工作区里的历史会话。Agent 等待审批、提问、完成或出错时，手机会收到提醒；点击提醒可直接进入对应会话（审批类会定位到待处理卡片）。手机端仍不能选择「始终允许」这类持久授权，也不能切换到绕过权限或完全访问模式——这些操作需要回到 PC。

## 当前版本能做什么

- 开启 / 关闭手机网关，并实时查看网关状态（已停止 / 正在启动 / 运行中 / 错误）。
- 用二维码或 8 位配对码把手机配对为受信任设备。
- 在同一台 PC 的默认浏览器中打开手机网页与配对页，方便没有手机时体验和排查。
- 查看已配对设备的名称、平台、配对时间、最近连接时间、在线状态与通知开关。
- 吊销设备。吊销后该设备的连接会立即断开，必须重新配对。
- 查看最近的配对、连接、吊销与网关事件（最近活动）。
- **查看收件箱**：按待审批 / 运行中 / 出错 / 已完成分组，显示 Agent、工作区、相对时间与待审批 / 提问徽标；远程会话与只读会话有标记，工作区有未提交修改时会显示「有修改」。
- **查看会话并交互**：计划、消息、思考、工具调用与 diff；审批、回答提问、发送 prompt、停止运行、切换模式 / 模型等配置、新建 / 重命名 / 关闭 / 移除会话。
- **分叉、回退与侧边任务**：从某条用户消息之前或会话末尾分叉出新会话；预览影响后回退到某条用户消息；以当前会话为上下文创建只读的侧边任务，并在会话菜单中查看、打开或删除。
- **历史会话**：从收件箱顶部的「会话」进入目录，搜索并重新打开 PC 当前已打开工作区里的历史会话；打开已关闭的会话不会切换 PC 的焦点。
- **收到通知**：等待审批、Agent 提问、完成或出错时提醒；可自选提醒类型与「PC 聚焦时也通知」。点击提醒直达会话，审批类直接定位到待处理卡片。

## 前置条件

- 手机与 PC 在同一 Tailscale 网络（推荐，可安装为应用并接收推送），或处于同一局域网。
- Tailscale 方案：PC 已安装并登录 Tailscale；手机也安装了 Tailscale 并登录同一账号。
- 局域网方案：PC 与手机连接同一个 Wi-Fi / 有线网络；首次启用时 PC 会生成自签证书。
- 手机使用现代浏览器（iOS Safari / Android Chrome）。

## 第 1 步：开启网关

1. 打开命令面板（`Ctrl+Shift+P`），执行 **首选项: 打开手机设备设置**。
2. 在「网关」一节打开 **启用手机网关**。
3. 状态会从「已停止」变为「正在启动…」，随后显示「运行中」以及监听地址（默认 `127.0.0.1:47321`）。

网关默认只监听回环地址（`127.0.0.1`），不会直接暴露到网络。

## 第 2 步：通过 Tailscale Serve 提供 HTTPS

手机要安装网页应用、使用推送等能力，需要一个安全上下文（HTTPS）。推荐用 Tailscale Serve 把本机回环端口暴露为 `https://<机器名>.<tailnet>.ts.net`：

```bash
tailscale serve --bg 47321
```

把 `47321` 换成设置页显示的端口。

然后：

1. 执行 **首选项: 打开手机网关配置 (JSON)**（也可以在「手机设备设置」页的「监听模式」一节点击 **编辑网关配置 (JSON)**）。
2. 把 Tailscale 给出的主机名加入 `allowedHosts`，例如：

```json
{
  "allowedHosts": ["pc.tailnet-name.ts.net"]
}
```

保存后设置会立即生效。回到设置页，「能力」一节中的「可安装为应用」和「推送通知」应变为「可用」，配对地址也会以 `https://` 开头。

> 手机网关的配置保存在这台电脑的用户数据目录（`<userData>/mobile/gateway.json`），不会写入 `settings.json`，也不随 `settings.json` 同步到其他电脑。这样同一账号在不同电脑上可以各自使用不同的监听方式。

> Tailscale 的 `*.ts.net` 主机名会出现在公开的证书透明度（CT）日志中。这是 Tailscale 签发证书的工作方式，请勿使用包含敏感信息的主机名。

> **WSL 用户**：WSL2 默认使用 NAT 网络，Windows 之外的手机无法直接访问 WSL 内的监听端口。
> 建议把 Tailscale 与编辑器都安装在 Windows 宿主上；如果必须在 WSL 内运行，需要使用
> `netsh interface portproxy` 做端口转发或启用 mirrored 网络模式，并放行 Windows 防火墙。
> 没有 Tailscale 时也可以改用下面的「局域网模式」，但同样受 WSL NAT 限制。

## 第 2b 步：局域网模式（可选）

没有 Tailscale、但手机与 PC 在同一网络时，可以把「监听模式」切换为 **局域网地址**：

1. 在「监听模式」中选择 **局域网地址**。网关会绑定本机局域网 IP，并默认用自动生成的自签证书提供 HTTPS。
2. 首次启用时 PC 会生成证书（约几百毫秒），状态区会显示 **证书指纹** 与到期时间。
3. 点击 **配对新设备** 并用手机扫码。浏览器会弹出「连接不安全」提示（自签证书的正常现象）。
4. 在该提示或浏览器的证书详情中查看证书的 SHA-256 指纹，与 PC 设置页显示的指纹逐段核对，一致后
   再接受证书并继续（不同浏览器操作不同）。**指纹不一致时不要继续**。配对页也会列出期望的指纹作为
   参照，但网页本身读不到实际证书，以浏览器证书详情为准。

如果 iOS 上反复出现「离线·重连中」，可把「局域网 HTTPS 证书」切换为 **根证书（需在手机安装）**：

1. 确认提示后，PC 会重新签发一张由本机根证书签发的叶证书；状态区会分别显示 **叶证书指纹**（浏览器警告里看到的）和 **根证书指纹**（需要在手机上安装的）。
2. 在手机 Safari 打开状态区给出的下载地址（形如 `https://<局域网 IP>:<端口>/api/cert`），下载描述文件。
3. iOS：设置 → 通用 → VPN 与设备管理 → 安装描述文件；再到 设置 → 通用 → 关于本机 → 证书信任设置，打开对该根证书的 **完全信任**。
4. Android：设置 → 安全 → 加密与凭据 → 安装 CA 证书。
5. 根证书每台 PC 独立。叶证书续签不需要重新安装根证书；但切换 IP、主机名或改用 Tailscale 会改变页面来源，手机上的配对凭据按来源隔离，需要重新配对。

限制：

- 局域网档只保证「遥控 + 加密」。**自签证书**下浏览器不把页面视为安全上下文，因此 **不能安装为
  应用，也不能使用 Web Push 通知**；iOS 上尤其不保证。需要这些能力请使用 Tailscale 档，或使用根证书模式并在手机上完全信任该根证书（PC 设置页无法探测手机是否已安装，因此仍会显示不可用）。
- iOS 会提示「本地网络」权限；Windows 首次监听非回环地址会弹出防火墙授权，请允许专用网络。
- 自签证书会在网络地址变化或临近过期时自动重新生成，重新生成后指纹会变化，需要重新核对。根证书模式的根证书在 10 年内复用，叶证书续签不改变根指纹。
- 配对页会在 IP 地址之外额外列出 **电脑主机名** 地址（形如 `https://<主机名>:<端口>`），作为 iOS 的备用入口。主机名可能同时解析到 Tailscale/WSL 等多个地址；若手机无法解析或连错地址，请继续使用 IP 地址。
- WSL2 NAT 下手机访问不到 WSL 内地址，需端口转发或 mirrored 网络模式（见上一节提示）。

## 第 3 步：配对新设备

1. 在「配对设备」一节点击 **配对新设备**。
2. 设置页会显示二维码、格式化后的配对码（`XXXX-XXXX`）和倒计时（约 2 分钟）。
3. 在手机上扫描二维码；也可以直接打开手机版首页，在「还没有配对」页下方的手动配对表单里输入配对码。
4. 配对成功后，二维码会自动收起并提示「设备配对成功」，设备会出现在下方的「已配对设备」列表中。

注意事项：

- 配对码是一次性的，且只在 PC 设置页显示；请勿截图或转发给他人。
- 点击 **取消** 或配对码过期后，需要重新生成。
- 有多个可用地址时（例如同时存在回环地址与 Tailscale HTTPS 地址），可以在二维码下方切换；优先选择 `https://` 地址。

### 在电脑浏览器中体验手机版（可选）

没有手机时，也可以用同一台 PC 的默认浏览器打开手机网页：

1. 确认「网关」显示 **运行中**，点击状态区的 **在电脑浏览器中打开手机版**。默认浏览器会打开手机网页；尚未配对时会显示「还没有配对」引导页，页内自带手动配对表单。
2. 要让这个浏览器进入收件箱，可以在「配对设备」中点击 **配对新设备** 后，把设置页显示的配对码填入引导页表单并点击 **开始配对**；也可以点击配对区的 **在电脑浏览器中打开配对页**，页面会预填一次性配对码，仍需点击 **开始配对** 确认。
3. 配对成功后，这个浏览器会作为一台设备出现在「已配对设备」中（名称可能显示为「手机」，平台为「其他」）；不再使用时可以吊销。它和手机浏览器一样受安全上下文限制：局域网自签证书下不能安装 PWA 或接收推送。
4. 局域网模式下打开 `https://` 地址时，浏览器会先提示证书不受信任；按第 2b 步核对指纹后再继续。

> **WSL**：如果点击按钮后没有自动弹出 Windows 浏览器，说明 WSLg 未能把链接交给浏览器。请手动打开设置页显示的地址（回环档通常是 `http://127.0.0.1:47321`，局域网档是 `https://<局域网 IP>:<端口>`），在引导页表单中输入设置页显示的配对码；也可以打开 `http://127.0.0.1:47321/pair` 后输入配对码。WSL2 下 Windows 浏览器通常可以通过 `localhost` 访问 WSL 内的回环端口；局域网模式可能还需要端口转发（见上文 WSL 提示）。

> 配对凭据保存在该浏览器的站点数据中；清除站点数据后需要重新配对。共享电脑上使用后请及时在「已配对设备」中吊销。

## 第 4 步：管理设备与吊销

「已配对设备」列表会显示：

- 设备名称与平台（iOS / Android / 其他）
- 配对时间与最近连接时间
- 是否在线
- 通知是否开启（「通知：已开启 / 未开启」）

点击设备行右侧的 **吊销** 并确认后，该设备会立即断开，之后必须重新配对。手机丢失或不再使用时，请及时吊销。

## 第 5 步：开启通知（可选）

通知默认关闭，需要在手机上开启：

1. 在手机 PWA 右上角打开 **设置**，找到「通知」一节。
2. 点击 **开启通知**。浏览器会弹出系统通知授权，选择「允许」。这一步必须由你在手机上直接点击，脚本或自动化无法代替。
3. 开启后可以选择提醒类型：**等待审批**、**Agent 提问**、**已完成**、**出错**。

开关与能力说明：

- 「安全上下文」「Web Push」「已添加到主屏幕」会显示当前是否可用；不可用时会给出具体原因与处理建议。
- 通知依赖 HTTPS。按第 2 步配置 Tailscale Serve 后，这三项才会显示可用。
- **iOS 要求**：iOS 16.4+，且必须先用 Safari 把页面「添加到主屏幕」，再从主屏幕图标打开后开启通知；在 Safari 普通标签页中无法接收推送。
- 「PC 聚焦时也通知」默认关闭。关闭时，只要 PC 上有窗口处于焦点，手机就不会收到提醒；打开后即使你在 PC 前也会提醒。
- 不使用通知时，点击 **关闭通知** 即可；PC 设置页的设备行会同步显示「通知：未开启」。

点击通知会打开对应会话；审批类通知会直接定位到底部的待处理卡片。手机应用在前台时，提醒会以应用内浮层出现，点击同样跳转。

**隐私说明**：

- 通知内容只包含会话标题与固定的类别文案（如「等待审批：<工具标题>」「Agent 提问」「已完成」「出错」），**不包含 prompt 正文、工具输出或你的回复**。
- 后台通知会经由 Apple / Google / Mozilla 等系统推送服务转发，因此内容保持最小化。PC 需要能访问公网。
- 推送订阅只保存在 PC 本机（`<userData>/mobile`），可随时在手机上关闭或在 PC 上吊销设备来清除。

## 手机端显示设置

在手机收件箱右上角打开 **设置**，可以调整三项只保存在本机的偏好：

- **外观 → 主题**：跟随系统（默认）、浅色或深色。选择后立即生效，刷新后保持；选择「跟随系统」时会随后续系统外观变化自动切换。
- **会话显示**：仅消息（默认）或完整显示。仅消息只保留用户消息、Agent 回复、错误与关键卡片（子 Agent、计划确认、待你决策的卡片），隐藏思考与普通工具调用；完整显示会展示全部时间线内容。
- **全屏显示**：浏览器支持网页全屏时显示 **进入全屏**，隐藏地址栏与工具栏；再次点击 **退出全屏**（或按 Esc / 使用系统返回手势）即可恢复。会话页也可以从右上角 **⋯ → 进入全屏** 快速切换。

iPhone 上的 Safari 不支持网页全屏（iPad 需要 iPadOS 16.4 或更新版本），设置中会显示相应说明。此时可以用 Safari 的 **分享 → 添加到主屏幕**，之后从主屏幕图标打开；应用会以独立窗口运行，不再显示浏览器界面。Android Chrome 也可以「添加到主屏幕」，效果相同。

## 最近活动

展开「最近活动」可以查看最近的配对、连接、吊销与网关事件，包括时间、设备、动作和结果。审计记录不包含 prompt 正文或设备令牌。

## 在手机上使用会话

配对成功后，在手机上打开配对地址即可进入收件箱：

1. **收件箱**按待审批、运行中、出错、已完成分组，组内按最近更新时间排列。
2. 每一行显示状态色点、会话标题、Agent、工作区与相对时间；有待审批 / 待提问、后台任务、远程工作区或只读会话时会显示对应徽标；工作区有未提交修改时显示「有修改」。
3. 向左滑动一行会露出 **关闭** 与 **移除**；长按同一行也会弹出相同操作。只读会话不提供这两个操作。
4. 点击一行进入会话页；从「需要你处理」分组进入时会自动定位到底部的待处理卡片。浏览器返回键或左上角返回按钮可回到收件箱；刷新页面会从当前地址恢复同一个会话。

会话页的内容与 PC 上保持一致：

- 顶栏显示标题、Agent 与运行状态；运行中的会话带有转圈图标。标题右侧的 **⋯** 菜单可以重命名、关闭或移除会话。**关闭**会结束 PC 上的会话并关掉对应标签页，但保留历史，之后可以在 PC 的会话列表里恢复；如果 Agent 正在运行、等待审批或还有后台任务，会先弹确认。**移除**会同时删除 Agent 端会话、子任务与历史记录，且不可恢复。只读会话不提供重命名、关闭与移除。操作成功后手机会返回收件箱并给出提示。
- 顶栏下方是配置项：模式 / 模型等选择项点击后从底部弹出选项列表，布尔项直接以开关呈现。
- 有执行计划时，顶部显示可折叠的「计划 已完成/总数」条。
- 时间线默认采用 **仅消息** 显示：依次展示用户消息、Agent 回复（Markdown）、错误与通知；思考与普通工具调用默认隐藏。流式回复会实时追加；向上滚动后若来了新内容，会出现「↓ 新消息」按钮。
- 在设置中切到 **完整显示** 后，时间线会重新展示思考（默认折叠）与全部工具调用；连续的工具调用会合并为「执行了 N 个操作」，展开后可查看单个调用的命令输出（ANSI 着色）与 diff。工具详情在展开时按需从 PC 拉取。
- 仅消息模式下，子 Agent、计划确认与等待你决策的卡片始终保留；子 Agent 卡片在手机上只显示入口行，不展示其内部时间线。
- 会话在 PC 上关闭后，手机端显示「会话已在 PC 上关闭」；如果该会话仍有历史记录，可以直接点击 **重新打开** 继续对话。

### 审批与提问

待审批 / 待提问会以底部卡片出现，卡片不会遮住最后一段对话；向下拖动或点击把手可以把它收成一行提示，待处理请求仍然保留。

- **审批**：点击选项即可提交。手机只显示允许在手机上操作的安全选项；「始终允许」等持久授权以及绕过权限 / 完全访问相关选项会被隐藏，并提示「部分选项需在 PC 上操作」。取消按钮会中止该请求。
- 若请求由 PC 处理，手机上的卡片会自动关闭并提示「已在 PC 上处理」。
- **计划自动执行倒计时**：Claude 计划审查类请求带有自动执行倒计时环。可以点击暂停 / 继续；暂停后倒计时停止，PC 与手机会保持同一状态。
- **提问**：文本 / 单选 / 多选 / 布尔 / 数字表单可以直接填写并提交；校验不通过时会在原地提示。仅提供链接的提问只展示链接与说明，手机不会自动打开。

### 输入与停止

- 底部输入框支持多行自动增高（最多 6 行），按回车换行；点击发送按钮提交。
- 输入框左侧的 **+** 打开附件选择：拍照、从相册选择、选择文件。也可以只发附件、不写文字。
- 图片作为图片附件直接交给 Agent（单张不超过 5 MB、最多 5 张）；其他文件会先上传到 PC 的临时目录，再以文件链接交给 Agent（单个不超过 25 MB）。一次最多 8 个附件、总大小不超过 50 MB。
- 上传中的附件会显示进度状态；上传失败时需要移除后重新选择。发送成功后，会话时间线里会显示图片缩略图或文件名与大小。
- 远程会话不能发送文件附件（Agent 读不到 PC 本地文件），但仍可发送图片；Agent 不支持图片时不会显示拍照与相册入口。
- 附件只临时保存在 PC 上，网关启动时会清空；PC 重启后，旧消息里的缩略图 / 文件卡可能无法再加载，但文字内容仍在。
- Agent 运行中也可以发送新消息（与 PC 一致，用于追加或调整方向）；运行中会显示 **停止** 按钮，点击后中止当前回合。
- 每个会话的未发送草稿保存在浏览器本地，切换会话或刷新后仍会恢复。
- 会话只读时输入框禁用；PC 离线时显示「PC 离线」并禁用输入，连接恢复后自动可用。

### 分叉、回退与侧边任务

用户消息和 Agent 回复右侧都有 **⋯** 按钮，点开后是对这条消息可用的操作。这些操作只在 Agent 支持对应能力且会话可写时出现。

- **回退到这条消息**：先弹出预览，显示会影响的文件数以及增删行数；确认后选择 **丢弃文件改动并回退**（撤销 Agent 这次改过的文件）或 **保留文件改动并回退**（只回退对话，保留磁盘上的改动），也可以取消。回退成功后，这条用户消息及其后的对话会从会话中移除，原文会自动填入手机输入框，方便修改后重新发送。填回的内容会覆盖手机输入框里尚未发送的草稿；PC 上的草稿不受影响。首条用户消息也可以回退；如果 Agent 无法回退（例如没有可用的检查点），预览会显示原因，且不提供回退按钮。
- **从此处分叉**：立即创建并打开一个新会话，它包含这条消息之前的历史，不改变 PC 当前打开的会话。会话正在运行时不能分叉，按钮会提示稍后再试；首条用户消息之前没有内容，因此首条消息只能回退、不能分叉。
- **就此追问**：以当前会话的完整历史为上下文创建侧边任务，并默认使用 Agent 的只读模式（仍可手动切换）；这条消息会作为引用填入侧边任务的输入框。用于在不打断主会话的情况下追问细节。

会话标题右侧的 **⋯** 菜单里还有：

- **从末尾分叉**：从当前会话的末尾分叉出一个新会话，包含全部历史。
- **新侧边任务**：创建一个不带引用的空白侧边任务。
- **侧边任务 (N)**：打开侧边任务列表。列表包含当前仍打开的和历史保存的任务；带「活动」标记的任务表示当前已在编辑器中打开（可能处于休眠状态，打开时会自动唤醒）。点击一行即可打开；点击右侧 **×** 可删除，删除会同时删除它的子任务且不可恢复。

侧边任务不会出现在收件箱列表中，需要从父会话的 **⋯ → 侧边任务** 进入；从通知或链接直接打开侧边任务时仍然可用。侧边任务页面顶部会显示 **来自：<父会话标题>**，点击可回到父会话。手机上的分叉、回退与打开侧边任务都不会切换 PC 当前会话。

### 新建会话

收件箱右下角的 **+** 进入新建会话页。页面固定显示「选择 Agent」和「选择工作区」两行当前选择：

1. 点击 **选择 Agent** 一行，在底部弹层中选择 Agent（默认 Agent 已预选）；选中后弹层自动关闭。
2. 点击 **选择工作区** 一行，在底部弹层中选择工作区。弹层顶部可以按名称或路径搜索，结果分为「已打开」和「最近」两组，列表在弹层内部滚动。已打开的工作区标记「已打开」，远程工作区标记「远程」，有未提交修改的工作区标记「有修改」（选中的工作区也会在页面上显示该标记）。选择未打开的工作区时，页面会提示「将在 PC 上打开此工作区」。
3. 可选填写初始 prompt，然后提交。创建成功后直接进入新会话。

### 历史会话

收件箱右上角的 **会话** 按钮会打开历史会话目录。目录只包含 PC 上 **当前已打开的工作区** 里的会话；PC 上没有打开该工作区时，它的历史记录在手机上不可见。历史记录中已归档、没有消息的会话以及侧边任务不会出现；仍留在收件箱里的会话会显示为 **活跃**，以收件箱数据为准。

- 顶部搜索框可以按标题、首条消息、Agent 或工作区筛选。
- **全部 / 活跃 / 已关闭** 可以只看仍在收件箱里的会话，或只看已经关闭、可以恢复的会话。
- 列表按「今天 / 昨天 / 更早」分组；置顶会话排在最前，其余按最近使用时间排列。
- 点击 **活跃** 会话会直接进入当前会话；点击 **已关闭** 会话会让 PC 重新恢复它，再进入会话页。恢复不会切换 PC 的焦点，也不会改变 PC 当前打开的会话。
- 从目录进入会话后再返回，会保留之前的搜索词、筛选条件与滚动位置。
- 打开一个已关闭会话的链接（例如旧通知）时，如果会话页显示「会话已在 PC 上关闭」，可以使用 **重新打开** 按钮恢复。

> 当 PC 离线或正在重连时，收件箱顶部会出现提示，列表保留最后一次数据但会置灰。连接恢复后会自动重新订阅，不需要手动刷新。

## 局域网模式与证书核对

「监听模式」中的 **局域网地址** 适合临时使用或没有 Tailscale 的环境：

- 网关默认自动选择局域网地址：优先物理网卡上的私有地址，并忽略 169.254 开头的链路本地地址。电脑有多块网卡（虚拟机、WSL、Tailscale 等）时，可在「监听模式」的地址下拉中手动指定。
- 网关绑定本机局域网 IPv4 地址，默认使用自签 HTTPS 证书；安装包版本同样可用。可在「监听模式」中切换为根证书模式。
- 证书与私钥保存在本机用户数据目录（`<userData>/mobile/tls`），权限仅当前用户可读；根证书模式的根证书与根私钥也保存在该目录，绝不会随状态或日志输出。
- PC 设置页显示证书的 SHA-256 指纹。**请在手机浏览器的证书详情中逐段核对**该指纹（配对页显示的只是
  二维码带来的期望值，网页读不到实际证书）；不一致可能意味着连接被中间人劫持，应停止配对并检查网络。根证书模式下要区分 **叶证书指纹**（浏览器警告里显示的）与 **根证书指纹**（手机上安装的），两者不同。
- 自签证书下无法安装 PWA、无法接收 Web Push 通知；这是浏览器的安全上下文限制，不是故障。
- 开发调试时可用环境变量 `UNIVERSE_MOBILE_INSECURE=1` 退回明文 HTTP，但打包版会拒绝；除排障外不要使用。

## 故障排查

- **状态一直是「已停止」**：确认「启用手机网关」已打开；如果通过环境变量启动，检查配置是否被覆盖。
- **状态为「错误」**：设置页会显示原因，常见的是端口被占用（`EADDRINUSE`）或没有权限（`EACCES`）。换一个端口或结束占用进程后重试。
- **手机打不开配对地址**：确认手机与 PC 在同一个 Tailscale 网络；确认 `tailscale serve --bg <端口>` 正在运行；确认 `allowedHosts` 中的主机名与 Tailscale 状态页一致。
- **二维码可以扫描但配对失败**：配对码可能已过期（约 2 分钟）。在 PC 上重新生成后再试。
- **「可安装为应用」「推送通知」显示不可用**：Tailscale 档请看是否已按第 2 步配置 Serve 与 `allowedHosts`；局域网档显示不可用属预期（自签证书不是受信任的安全上下文）。
- **手机提示证书不安全 / 指纹不一致**：局域网档需要接受自签证书后再继续；若浏览器证书详情中的指纹与 PC 显示的不一致，请勿配对，检查是否有代理或中间人。
- **局域网地址连不上**：确认手机与 PC 在同一网段、Windows 防火墙已允许专用网络、WSL 已做端口转发或使用 mirrored 网络；地址变化后证书会重签，需要重新扫码。
- **手机一直显示「离线·重连中」**：连续重试约 3 次后，手机会显示连接诊断卡：
  - **无法访问 `<地址>`**：手机没有收到 PC 网关的 HTTP 响应。依次检查：手机与 PC 在同一 Wi-Fi / 局域网；iOS 设置 → 隐私与安全 → 本地网络 已允许 Safari / Chrome；关闭手机上的 VPN、代理、私人中继；PC 网关仍在运行且防火墙允许专用网络；浏览器证书警告已被接受。
  - **已到达 PC，但 WebSocket 握手失败**：网络是通的，问题在证书信任或 WebSocket。局域网档可安装根证书（诊断卡提供下载入口），或改用 Tailscale 档；使用主机名时确认手机能解析到 PC 的局域网 IP。也可先用隐私窗口打开页面，排除 Service Worker 缓存。
  - 诊断卡上的 **立即重试** 会跳过退避立刻重连，**重新检查** 会重新探测 HTTP 连通性。
- **设置了根证书但手机仍提示不安全**：只在 PC 上下载根证书还不够，必须在手机上安装描述文件，并在「证书信任设置」中打开完全信任；确认安装的是根证书指纹，而不是连接时浏览器警告里的叶证书指纹。
- **开启了通知但收不到提醒**：确认系统通知权限已允许；iOS 需从主屏幕图标打开；确认对应提醒类型已勾选。PC 窗口聚焦时默认不发手机通知，可打开「PC 聚焦时也通知」。PC 离线或没有公网时后台推送也会失败。
- **手机提示「版本不一致，请刷新页面」**：PC 编辑器更新后手机协议版本升级，旧页面或已安装的 PWA 仍在用旧版本。在手机浏览器中刷新页面；已添加到主屏幕的应用可从应用切换器中彻底关闭再重新打开。刷新不会丢失配对凭据。

更多排障说明见 [排障指南](../reference/troubleshooting.md)，设置项说明见 [设置](../customization/settings.md)。
