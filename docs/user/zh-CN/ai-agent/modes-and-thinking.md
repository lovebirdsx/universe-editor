# 模式与思考等级

[Agent](../reference/glossary.md#智能体--agent) 有两个作用于**当前会话**的调节旋钮：[模式](../reference/glossary.md#模式agent-模式)和[思考等级](../reference/glossary.md#思考等级)。这一页讲它们各是什么、什么时候用哪种。

## Agent 模式

- 命令："选择 Agent 模式…"
- **作用**：切换 Agent 的行为模式。具体有哪些可选项，由当前 Agent 提供——不同 Agent 暴露的模式不一样（例如偏只读咨询、或允许改文件等）。
- 当前 Agent 不提供模式选择时，会提示"活跃 Agent 未提供会话模式选择器。"

## 思考等级

- 命令："选择 Agent 思考级别…"
- **作用**：调节 Agent 推理投入的深度。等级越高，思考越细致，但也**越慢、越贵**。
- 当前 Agent 不提供思考级别开关时，会提示"活跃 Agent 未提供思考级别开关。"

<!-- 截图：思考等级选择器 -->

## 什么时候用哪种

- **简单的批量替换、查找** → 低思考等级就够了，又快又省。
- **需要设计、推理、跨文件重构** → 提高思考等级，让它想得更周全。

## 注意事项

- 这两项都作用于**当前活跃会话**，需要先有一个活跃会话。
- 它们**依赖 Agent 的能力**：如果当前 Agent 没提供对应选项，命令会弹出上面的提示，属正常现象。
- 思考等级直接关系到花费，调高前先想想这个任务是否值得——见 [模型选择与花费](./models-and-cost.md)。
- **Codex 的「Auto review」在自定义 provider 下不可用**：该模式不把提权审批交给你，而是交给 Codex 自带的评审模型（`codex-auto-review`），请求走当前配置的 provider。自定义 provider（例如自建网关）通常没有这个模型，审批一律失败，而 Codex 不允许绕过失败的评审——于是写 `.git`、写工作区外、联网等所有需要提权的操作全都会失败（表现为 Agent 迟迟不肯提交）。会话落到这个组合时编辑器会弹一条警告，点其中的「切换到 Workspace access」即可改成由你本人审批；模式菜单里的「Auto review」也会带标注。用官方订阅或官方 API key 时没有这个问题。
- 计划确认卡按 Agent 提供的顺序展示全部选项，可分别选择清空上下文、保留上下文自动审批、手动审批或继续规划（具体选项取决于 Agent）。「clear context」会以计划为起点重新开始模型上下文，只在你手动选择时触发。
- 计划（Plan）模式下，Agent 为 Shell 命令、文件读取与搜索提供带作用域的「允许并记住」选项（例如「Yes, and allow access to … commands」）时，编辑器**默认替你选中**、不再逐条弹权限卡：Agent 会应用该选项携带的受限规则——通常是会话级；Shell 命令规则可能写进工作区 `.claude/settings.local.json`。Agent 标记为需要明确回答的请求（拒绝项排在第一位）绝不自动批准。可用设置 `acp.plan.autoApproveWithUpdates` 关掉，恢复每次人工确认。
- 计划（Plan）模式完成计划后，确认卡片上可勾选「此后自动执行计划」：之后每次计划完成都会经短暂倒计时自动以 bypass 模式继续——悬停或聚焦卡片会暂停倒计时，移开并失焦后继续；手动改选或取消勾选可停止本次自动执行。计划制定过程中 Agent 向你提问时，提问面板上也有同一开关，提前勾选则计划完成即自动执行。想换成其他自动执行模式，用设置 `acp.plan.autoExecute`。自动执行只选择对应模式的**保留上下文**选项；Agent 未提供该选项时改由你人工确认，不会自动切换其他模式或清空上下文。带自动执行倒计时的确认卡片**不会弹系统通知**（它自己会继续，无需你介入）；整轮任务结束回到空闲时仍照常通知。

**本页涉及的命令：**

| 命令面板名称 | 快捷键 | 作用 |
| --- | --- | --- |
| 选择 Agent 模式… | 无 | 切换 Agent 行为模式 |
| 选择 Agent 思考级别… | 无 | 调节推理深度 |
