## 技能 Skills

技能是放在项目 `.claude/skills` 目录下的**可复用能力包**。

- 在输入框里敲 `/`，可以看到当前可用的技能列表。
- 举个例子：做一个"按模板生成任务文案"的技能，之后每次让 Agent 生成文案，它都会按你的规范产出，不用每次重复交代格式。

## 记忆 Memory

记忆让 Agent **跨会话记住**关于你项目的事情，省得每次重新解释。

- 结构：`.claude/memory/MEMORY.md` 是索引，加上若干分篇正文。
- Agent 每轮会自动读索引，按需读取相关分篇。
- 适合记什么：项目设定、术语译法、写作风格等——比如"HP 一律写成生命值"这类约定，写进记忆后 Agent 就会一直遵守。

## 一套配置服务两个 Agent

同一个项目的 `.claude/` 目录（技能与记忆）会**同时服务两个内置 Agent**（Claude Code 与 Codex）。配置一次，两个 Agent 都能用。

## MCP：接入外部工具

MCP（Model Context Protocol）是一套让 Agent 接入外部工具和数据源的协议。

**定义服务器**有两处来源，合起来构成可选的服务器池：

- 全局：设置项 `acp.mcpServers`（命令"打开 MCP 设置"直达 AI 设置里的"MCP 服务器"面板）。在条目里加 `"disabled": true` 可以保留定义但默认不启用。
- 项目：工作区根目录的 `.mcp.json`，按服务器名覆盖全局同名条目——适合把"这个项目才用得到"的服务器随仓库带走。

**可视化配置**：AI 设置的"MCP 服务器"面板按来源分组列出所有服务器——User（全局 `settings.json`）与 Workspace（项目 `.universe-editor/settings.json`）两组可以直接在界面里添加、编辑、启停、删除；`.mcp.json` 一组只读展示、可一键打开文件。同名条目按"项目覆盖全局"合并，被覆盖的行会标注"overridden by …"而不是悄悄消失；格式有误、运行时会被跳过的条目也会就地给出警告。每行右侧的状态点反映当前会话里该服务器的实时连接状态（已连接/连接中/失败）。

**按会话开关**：大部分服务器并不需要全程在线。会话输入框上方配置条里有一个 MCP 按钮（显示"已启用数/总数"），点开后勾选需要的服务器即可：

- 改动立即生效——会话会在后台自动重连，对话记录保留。
- 左侧勾选只作用于当前会话；行右侧的「默认」开关决定之后新会话启用哪些（与 AI 设置面板里的启停是同一个开关）。
- 注意：重连会使模型的提示缓存失效，下一轮对话的响应会慢一些、消耗也会高一些，弹层里有相应提示。
- 被 `disabled` 的服务器不会自动启用，但可以在这里单独勾选开启。

AGENTS 容器里的"MCP 服务器"视图，可以查看当前会话已连接的服务器；没有时提示"此会话没有配置 MCP 服务器。"

## 该从哪开始

这三样的共同价值是**让 AI 更懂你的项目、少解释、结果更一致**。刚开始不用全上：

- 有反复交代的约定 → 写进记忆。
- 有固定套路的产出 → 做成技能。
- 需要接外部工具/数据 → 再研究 MCP。

**本页涉及的命令：**

| 命令面板名称  | 快捷键 | 作用            |
| ------------- | ------ | --------------- |
| 打开 MCP 设置 | 无     | 配置 MCP 服务器 |
