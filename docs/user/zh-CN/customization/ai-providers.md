## 两个入口

配置 AI 供应商有两个入口，改的是同一份数据：

- **图形界面**：命令面板运行「打开 AI 与 Agent 设置」，打开可视化的 AI 设置编辑器，添加实例、验证、管理模型都在这里。推荐日常使用。
- **JSON 文件**：命令面板运行「打开 AI 设置（JSON）」，直接编辑配置文件 `aiSettings.json`，适合高级用户。

按 `Ctrl+Shift+P` 打开[命令面板](../reference/glossary.md#命令面板)后，输入上面的命令名即可。

## 添加一个供应商实例

AI 供应商分两层：**类型**（协议、模型目录与费率，例如 `openai`、`ollama`）和**实例**（一份具体的连接配置）。同一个类型下可以有多个实例，它们共享该类型的模型与费率。添加步骤：

1. 在 AI 设置编辑器里点「添加提供方」。
2. 先选一个类型（也可以「新建类型」并指定协议），然后填写下面几个字段：

   | 字段 | 说明 |
   | --- | --- |
   | 类型 | 选择服务类型（例如 `openai`、`ollama`） |
   | 名称 | 给这个实例起个好认的名字（同一类型下唯一） |
   | Base URL | 服务地址，留空则用该类型的默认地址 |
   | API 密钥 | 访问服务的密钥，可选（本地服务通常不需要） |

3. 点「验证」，编辑器会尝试连接并列出可用[模型](../reference/glossary.md#模型)的数量；连接失败会显示错误原因。

添加好的实例会显示徽标：有没有配密钥、枚举到多少个模型，一目了然。

## 管理实例里的模型

每个实例下面会列出自动枚举到的模型。你还可以：

- **手动添加模型**：填入该服务所需的模型 id，用于枚举不到但确实可用的模型。
- **配置模型**：调整单个模型的参数。
- **移除模型 / 移除实例**：删掉不再需要的条目。

## 接入 OpenAI 兼容端点

很多本地或第三方服务（如 LM Studio、vLLM、DeepSeek 等）提供「OpenAI 兼容」的接口。接入方法：

1. 类型选 `openai`。
2. Base URL 填入该服务的兼容端点地址。
3. 如果该服务不需要认证，API 密钥留空即可（连接时会省略认证信息，不会报错）。

## 接入本地部署的 Ollama

如果你在本机跑了 Ollama：

1. 类型选 `ollama`。
2. Base URL 通常无需填写，默认就是本机的 Ollama 地址 `http://127.0.0.1:11434`。
3. 本地服务无需 API 密钥。

## 设置与清除 API 密钥

除了在添加实例时填写，你随时可以单独管理密钥。

**在图形界面里**：进入某个实例的详情，用「编辑 API 密钥」和「清除 API 密钥」按钮操作。密钥会以掩码显示（未设置时显示「未设置」）。

**用命令面板**：

- 「设置 AI 提供方 API 密钥」：先选一个实例，再输入密钥。
- 「清除 AI 提供方 API 密钥」：选一个实例，确认后清除。

## 密钥安全：你需要知道的

API 密钥是敏感信息。编辑器的保管方式是一个**有意的设计取舍**，请记住这几点：

1. **明文保存在 `aiSettings.json` 里。** 为了让你能在多台机器之间同步同一份 AI 配置，密钥会直接写进 AI 设置文件的 `apiKey` 字段，不再使用操作系统的加密存储。
2. **权限尽量收紧。** 在类 Unix 系统上，编辑器会把该文件设为仅本人可读写（权限 0600）；Windows 上则依赖你用户目录本身的权限保护。
3. **界面上始终掩码显示。** 密钥只显示前 4 位和后 4 位；它不会被写进日志，也不会出现在 AI 调用记录（AI Debug）里。

> ⚠️ 正因如此，**`aiSettings.json` 里含有你的密钥**，请务必注意：
>
> - **不要**把它提交到公共版本库，也**不要**随工作区分享给别人。
> - 放进云同步目录（网盘、iCloud、OneDrive 等）时，请确认该目录可信。
> - 分享配置给别人之前，请先删掉各实例的 `apiKey` 字段。

**请不要**把密钥写进其它任何设置文件——编辑器只认 `aiSettings.json` 里实例的 `apiKey` 字段。

## 配置文件里有什么

如果你打开 AI 设置文件 `aiSettings.json`，会看到这些内容：

- `providerTypes`：自定义或覆盖的供应商类型（协议、模型目录、费率等），不覆盖内置类型时通常为空。
- `providers`：你添加的供应商实例，含名称、类型、Base URL、模型列表，以及 `apiKey`（密钥，明文）。
- `activeModels`：当前为对话、内联补全等分别选中的模型 id。

例如：

```jsonc
{
  "providers": [
    {
      "name": "default",
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKey": "sk-这里换成你的密钥"
    }
  ],
  "activeModels": {
    "chat": "openai/default/gpt-4o"
  }
}
```

> 上面 `apiKey` 用的是占位值；实际文件里会是你的真实密钥，所以这个文件请勿公开分享。

文件缺失或为空时，编辑器不会合成任何默认实例，你需要在 AI 设置里自己添加。
