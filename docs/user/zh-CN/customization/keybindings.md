## 打开快捷键编辑器

快捷键编辑器是查看和修改所有按键绑定的地方。打开方式：

1. 依次按 `Ctrl+K` 和 `Ctrl+S`（这是一个两段式快捷键，先按 `Ctrl+K`，松开后再按 `Ctrl+S`，详见[弦和键](#弦和键两段式快捷键)）。
2. 或按 `Ctrl+Shift+P` 打开[命令面板](../reference/glossary.md#命令面板)，输入「打开键盘快捷方式」。
3. 或从菜单栏「文件 → 首选项 → 打开键盘快捷方式」。

## 看懂快捷键编辑器

编辑器以表格形式列出全部命令（包括尚未绑定按键的命令），主要有四列：

| 列 | 含义 |
| --- | --- |
| 命令 | 这个快捷键会执行哪个操作 |
| 键绑定 | 当前绑定的按键 |
| When | 这条绑定在什么场景下生效的条件表达式（空表示任何时候） |
| 来源 | 「系统」自带、来自某个「扩展」，还是你自己设的「用户」绑定 |

- **顶部搜索栏**：输入命令名或按键即可过滤，匹配片段会高亮。还支持进阶语法：
  - `@source:user` / `@source:system` / `@source:extension`：按来源过滤；
  - `@command:命令ID`：精确查某个命令；
  - `"ctrl+shift+p"`（带英文引号）：按键位精确匹配；
  - **录制键搜索**（搜索框旁的录制按钮，或 `Alt+K`）：开启后直接按下组合键，编辑器会把它转成精确搜索，找「这个键当前绑给了谁」最方便，按 `Esc` 退出录制。
- **按优先级排序**（`Alt+P`）：把列表从字母序切换成快捷键实际生效的优先级顺序，排查同键冲突时有用。
- 鼠标悬停或选中某行时，行首会出现铅笔（已有绑定）或加号（尚无绑定）图标，点击即可修改。
- 表格支持键盘操作：搜索框内按 `Ctrl+Down` 进入表格，方向键移动选中行，`Enter` 修改按键。

## 绑定一个新按键

1. 在搜索栏里找到你想绑定的命令。
2. 点击该行左侧的铅笔/加号图标，或选中该行按 `Enter`（双击该行也可以）。
3. 屏幕中央弹出录制框，直接按下你想用的组合键，按下的键会实时显示；两段式快捷键连续按两段即可。
4. 按 `Enter` 确认；想放弃录制，按 `Esc`（已按过键时第一次 `Esc` 先清空重录，再按一次才关闭）。

<!-- 截图：录制新按键的浮层 -->

> 提示：如果你按的组合键已经被别的命令占用，录制框会显示「N 个现有命令使用此键绑定」，点击这行提示即可跳转查看是哪些命令，再决定是否继续。

## 右键菜单：更多操作

在任意一行上右键，可以：

- **复制**该条绑定的 JSON / 命令 ID / 命令标题；
- **更改键绑定**（`Enter`）或**添加键绑定**（`Ctrl+K Ctrl+A`）——同一个命令可以同时绑多个按键；
- **移除键绑定**（`Delete`）：让这个按键不再触发该命令；
- **重置键绑定**：撤销你的修改，恢复默认（仅对你改过的条目可用）；
- **更改 When 表达式**（`Ctrl+K Ctrl+E`）：就地编辑生效条件，输入时会提示可用的条件名；
- **显示相同键绑定**：一键搜出所有用同一个按键的命令。

## 弦和键：两段式快捷键

有些快捷键是「两段式」的，需要依次按两次，例如 `Ctrl+K Ctrl+S`：

- 先按住 `Ctrl` 敲 `K`，松开；
- 再按住 `Ctrl` 敲 `S`。

这类快捷键在 JSON 里写成一个字符串，中间用空格分隔，例如 `'ctrl+k ctrl+s'`。打开快捷键编辑器本身的 `Ctrl+K Ctrl+S`、以及打开快捷键 JSON 的 `Ctrl+K Ctrl+K`，都是弦和键。

## 直接编辑 JSON

想批量调整或复制粘贴分享配置时，直接编辑 JSON 更快：

1. 依次按 `Ctrl+K` 和 `Ctrl+K`（同一个键按两次），或在命令面板搜「打开键盘快捷方式 (JSON)」。
2. 文件里每条绑定是一个对象：

```json
[{ "key": "ctrl+alt+n", "command": "agent.newSession", "when": "..." }]
```

- **`key`**：按键组合，弦和键用空格分隔两段。
- **`command`**：要触发的命令 ID。在命令 ID 前加 `-`（减号）表示移除这条默认绑定。
- **`when`**：可选，控制这条快捷键在什么场景下生效（例如只在编辑器聚焦时）。不确定就先不写。

## 从 VSCode 沿用快捷键

如果你在 VSCode 里已经调好了一套快捷键，可以直接沿用：

- 命令面板运行「打开 VS Code 键盘快捷方式 (JSON)」，会打开 VSCode 的快捷键文件。
- 若你没装过 VSCode 或该文件不存在，编辑器会给出提示。
