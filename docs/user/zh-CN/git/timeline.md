# 时间线视图（单文件历史）

时间线视图按时间顺序列出**当前文件**的版本历史，点一下就能对比任意两版之间的差异。它跟着你打开的文件走——切到哪个文件，就显示哪个文件的历史。

## 时间线视图在哪

时间线放在主侧边栏的**资源管理器**容器里，和文件树是同一个侧栏里的另一个视图。打开项目后，把资源管理器侧栏往下翻就能看到 **"Timeline"（时间线）**。

> 视图标题目前显示英文 **"Timeline"**。

## 打开时间线

除了一直开着它跟随当前文件，还可以在资源管理器的文件树里**右键某个文件 → "Open Timeline"（打开时间线）**：侧栏会自动展开，时间线钉在这个文件上（见[固定与筛选](#固定与筛选)）。

> 这个菜单项只在项目里有时间线来源（比如项目是 [Git 仓库](./overview.md)）、且右键的不是文件夹时才出现。

## 看某次提交改了什么

列表里每行是一次[提交](../reference/glossary.md#提交--commit)：图标、提交说明、右侧是距今的相对时间（如"3 小时前"）。

**点击任意一行**，编辑器会打开一个差异视图：左侧是该次提交之前的版本，右侧是该次提交的版本，直观看出这次提交对这个文件改了什么。差异视图标题里带提交的短哈希（如 `a.ts (abc1234)`）。

**悬停某一行**时，行尾会出现两个按钮：第一个 **"Open Commit"（打开提交）** 打开这次提交的全部改动（见下节）；第二个跳转按钮在 [Git 图谱](./git-graph.md)里定位到该次提交（见"在图谱中查看提交"一节）。

## 打开提交的全部改动（Open Commit）

单击一行只能看到这次提交对**当前这一个文件**的改动。想看这次提交**改动的所有文件**——每个文件一节、同页对比——用 **"Open Commit"（打开提交）**：

- **行内按钮**：悬停某一行，点行尾第一个按钮（差异图标，悬停提示 "Open Commit"）；
- **右键菜单**：对某一行点右键，选 **"Open Commit"**。

两个入口都会打开源代码管理侧栏的"提交变更"视图：顶部是提交标题、作者与时间（悬停标题会以悬浮提示显示完整提交信息，含正文所有行），下面按文件列出这次提交的全部改动，并自动把焦点定位到当前文件那一行。点击任一文件行，编辑器会打开该文件在这版与上一版之间的差异。键盘操作与源代码管理视图一致：方向键移动，**空格**预览差异（焦点留在文件列表上），**回车**打开差异并聚焦编辑器；命令面板里的 **"Focus on Commit Changes View"** 可随时把焦点移回该视图（再次聚焦时会回到上次浏览的文件行）。"未提交的更改"行没有这个入口。

"提交变更"视图的标题栏还有几个操作：**在图谱中显示**（跳转图标）会打开 [Git 图谱](./git-graph.md)并定位到这次提交；**全部折叠 / 全部展开**一键收起或展开文件树的所有文件夹；**"…"菜单**里可在树形与列表两种布局之间切换——列表模式平铺所有文件、文件名后面灰色显示所在目录，树形模式靠文件夹层级表达路径。布局选择会被记住，下次打开仍然生效。

## 在图谱中查看提交

想看某次提交在整个仓库历史里的位置（同一提交还改了哪些文件、在分支链上的前后文），不用自己打开图谱再搜：

- **行内按钮**：悬停某一行，点行尾出现的跳转按钮；
- **右键菜单**：对某一行点右键，选 **"Open in Git Graph"（在 Git Graph 中显示）**。

两个入口都会打开 [Git 图谱](./git-graph.md)并**选中、滚动定位到该次提交**——即使这次提交很老、还没加载进图谱（图谱会按需自动向前翻页，最多补 20 页，找不到则不动当前选中）。点击入口的同时，时间线列表里的选中行也会移动到该条目上。"未提交的更改"行没有这个入口。

## 未提交的更改

如果当前文件有还没提交的改动，列表最上方会多一行 **"Uncommitted Changes"（未提交的更改）**。点击它会对比「[HEAD](../reference/glossary.md) 版本 ↔ 当前工作区文件」，即你此刻手头的全部改动。

未被 git 跟踪的新文件（没有 HEAD 版本）不会显示这一行。

> 这行以及相对时间目前是英文原样显示。不想看到它，可以在设置里关掉 `git.timeline.showUncommitted`（见[相关设置](#相关设置)）。

## 右键菜单

对任意一行点右键：

- **Open Comparison**（打开比较）：同单击，打开与前一版本的差异。
- **Open Commit**（打开提交）：打开这次提交的全部改动（见[打开提交的全部改动](#打开提交的全部改动open-commit)）。
- **Copy Commit ID**（复制提交 ID）：把这次提交的完整哈希拷到剪贴板。
- **Copy Commit Message**（复制提交信息）：把提交说明拷到剪贴板。
- **Open in Git Graph**（在 Git Graph 中显示）：打开图谱并定位到该次提交（见[在图谱中查看提交](#在图谱中查看提交)）。

## 固定与筛选

视图标题栏上有两组操作：

- **固定（图钉）**：默认情况下时间线跟随活动编辑器切换。点一下图钉，时间线就钉在当前文件上，之后随便切文件它都不动；再点一次解除固定，恢复跟随。跟随时如果焦点切到没有文件的视图（如 Git Graph、设置页），时间线会停留在上一个文件上，不会变空。
- **筛选来源（"…"菜单 → Filter by Source）**：当多个来源都提供历史时（目前内置的是 **Git History**），可以勾选只显示其中一部分。

历史较长时，列表底部会出现 **"Load more"（加载更多）**，点它再取一页。

## 相关设置

在设置里搜 `timeline` 或 `git.timeline`：

- `timeline.pageSize`：每次加载多少条历史（默认 50，也是"加载更多"每页的量）。
- `git.timeline.showUncommitted`：是否在列表顶部显示"未提交的更改"一行（默认开）。
