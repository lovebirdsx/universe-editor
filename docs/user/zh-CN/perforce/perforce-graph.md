# 提交历史图（Perforce 图谱）

Perforce 图谱是一个专门用来**可视化浏览已提交 changelist 历史**的编辑器。想看清"仓库里依次提交了哪些改动"、或直接对某个 changelist 查看/对比它改了哪些文件，这里是最佳入口。

> 与 Git 不同，Perforce 的历史是一条**严格编号、线性排列的 changelist 列表**（没有本地分支合并那样的分叉），所以图谱是**单条泳道**。界面、搜索、右键菜单都与 [Git 图谱](../git/git-graph.md) 保持一致的使用体验。

## 打开 Perforce 图谱

三种方式：

- 命令面板运行 **View Perforce Graph**（查看 Perforce Graph）；
- 点 Perforce 源代码管理侧栏标题栏最左边的图谱图标；
- 或点击底部状态栏左侧的当前客户端名称。

> 命令面板里这条命令显示的是英文 **"View Perforce Graph"**（分类 "Perforce Graph"），搜索时请用英文。

打开后是一个编辑器标签页，标题为 **"Perforce Graph"**。

也可以"带着目标 changelist 来"：从[时间线](./daily-workflow.md#时间线文件历史)历史行的行内按钮 / 右键菜单，或 Blame 悬停卡片里的 **"Open in Graph"** 链接——图谱会直接**选中并滚动定位到该 changelist**，未加载时自动向前翻页查找（最多补 20 页）。如果你已经在用"提交变更"视图，它还会自动跟随切换为该 changelist 的改动（静默更新，不会弹出侧栏或抢焦点）。

> 想直接看某个 changelist **改动的全部文件**（而不是它在历史里的位置），在图谱里单击该 changelist 即可，或用时间线的 [Open Commit](./daily-workflow.md#时间线文件历史)（历史行行内第一个按钮 / 右键菜单），或点击状态栏 Blame 项。

## 只看一个文件或文件夹的历史

除了纵览整个仓库，你还可以把图谱限定到**单个文件或文件夹**，只查看影响该路径的已提交 changelist 历史。

**三个入口：**

- **资源管理器右键**：在某个 Perforce 文件或文件夹上右键 → **Perforce ▸** 子菜单 → **View File History**（查看文件历史）。
- **源代码管理视图文件行右键**：在文件行上右键 → **View File History**。
- **命令面板**：运行 **View File History**，作用于当前活动编辑器的文件。

打开后是一个独立的编辑器标签页，标题为 **"History: <文件名/文件夹名>"**。

**与时间线的区别：** 侧栏的[时间线](./daily-workflow.md#时间线文件历史)把某个文件的**逐条修订**排成一个列表，适合逐条翻看每次改动；而"文件历史"复用 [Perforce 图谱](#打开-perforce-图谱)的**图谱式**展示——每条提交一行，可以[搜索 changelist](#搜索-changelist)、单击某条提交会在源代码管理侧栏的"提交变更"视图里列出它改了哪些文件，`Ctrl+F` / `Ctrl+Shift+R` / `Ctrl+R` 这些快捷键也照常生效。

**为什么看不到地球图标和仓库下拉：** 这类限定到单个路径的历史标签页**不会显示**工具栏上的"整个仓库"地球开关，也没有客户端（workspace）下拉——它的范围已经由你右键的路径固定下来，没有"当前目录 vs 整个仓库"或"切换客户端"的余地。想看整个仓库的历史，用普通的 [Perforce 图谱](#打开-perforce-图谱) 标签页。

**可以同时开多个：** 每个文件/文件夹的历史各自占据一个标签页、互不影响——搜索内容、选中的 changelist 都是各自独立的，切换、关闭其中一个不影响其它。

## 图谱里能看到什么

- **每行一个已提交的 [changelist](../reference/glossary.md#源代码管理scm)**，左侧是单条连线泳道，右侧有 changelist 编号、作者、工作区（client）、日期、描述等列。
- 最顶部有一行 **"待定变更"**，代表你当前已签出（opened）但还没提交的改动，与 Git 图谱里"未提交的更改"节点对应。点击它会跳转到源代码管理视图。
- **单击某个 changelist**，源代码管理侧栏的"提交变更"视图会列出它改了哪些文件，并按状态着色（已添加 / 已修改 / 已删除 / 已重命名）。点击文件行会打开该文件这次改动的差异。视图标题栏还提供"在图谱中显示"（定位当前 changelist）、全部折叠 / 全部展开，以及"…"菜单里的树形 / 列表布局切换（选择会被记住）。键盘操作与源代码管理视图一致：**空格**预览差异（焦点留在文件列表）、**回车**打开差异并聚焦编辑器；命令面板的 **"Focus on Commit Changes View"** 可随时聚焦该视图。

顶部还有"加载更多变更"，用于翻看更早的历史（默认一次加载最近若干条）。

## 键盘导航

打开图谱时焦点就在变更列表上，无需先点击，整个图谱都可以纯键盘操作，与 [Git 图谱](../git/git-graph.md#键盘导航) 一致。没有历史记录可恢复时，会自动选中首个 changelist（跳过"待提交更改"行），并像单击一样在"提交变更"视图显示它的改动；上次聚焦的 changelist 会被记住，下次打开（包括重启应用后）仍保持选中并滚动定位到它：

- **↑ / ↓**：上移 / 下移选中 changelist，"提交变更"视图会像单击一样跟随切换。
- **Home / End**：跳到第一行 / 最后一个已加载的行（不会自动触发"加载更多变更"）。
- **PageUp / PageDown**：按当前可视行数翻页移动选中。
- **Enter**：把焦点移入"提交变更"视图的文件列表，接着用键盘翻看该 changelist 改了哪些文件（**空格**预览差异、**回车**打开差异）。
- **Ctrl+Enter**：对当前选中 changelist 弹出与右键相同的操作菜单，锚点在选中行位置。
- 弹出的菜单同样支持键盘：**↑ / ↓** 移动高亮（自动跳过分隔线），**Enter** 执行，**Esc** 关闭。

## 只看当前目录，还是整个仓库

默认情况下，图谱只显示**当前打开目录**下的 changelist 历史——也就是你实际在编辑的那部分，而不是整个 Perforce 仓库。

工具栏刷新按钮左侧有一个 **地球图标** 开关：

- **未激活**（默认）：只列出当前打开目录范围内的提交历史。
- **激活**（高亮）：切换为显示整个仓库（client depot）的提交历史。

这个开关会**按工作区记住**，下次打开同一项目时保持你上次的选择。

## 搜索 changelist

图谱编辑器处于激活状态时，按 `Ctrl+F` 聚焦搜索框（占位文字"搜索变更…"），输入编号、作者或描述关键词快速定位。

> 命令面板里这条对应 **Focus Search**（聚焦搜索），且只在 Perforce 图谱编辑器激活时才生效。

想按描述、编号或作者**跳转**到某个 changelist，也可以在图谱激活时按 `Ctrl+R`（**Go to Symbol in Editor…**，转到编辑器中的符号）：弹出的列表按图谱顺序列出所有已加载 changelist，右侧带"编号 · 作者 · 日期"，上下键浏览只滚动预览，回车选中该 changelist 并像单击一样在"提交变更"视图展示它的改动。

## 刷新图谱

图谱会自动跟随服务器上的新变化刷新；需要手动拉一遍最新历史时，在图谱激活时按 `Ctrl+Shift+R`，或运行命令 **Refresh**（刷新，分类 "Perforce Graph"），与工具栏的 ↺ 按钮等效。

> 命令面板里这条同样显示英文 **"Refresh"**，且只在 Perforce 图谱编辑器激活时才生效。

## 右键即操作

在某个 changelist 上**右键**可执行：

- **复制变更号**：拷贝该 changelist 的编号。
- **复制提交信息**：拷贝该 changelist 的完整描述文字（含所有行）。鼠标悬停在描述上也会以悬浮提示显示完整内容。
- **发送到 Agent Chat**（Send to Agent Chat）：把这个 changelist 的编号和描述发到 AI 会话的输入框，方便让 agent 结合这次改动回答问题。没有活动会话时会自动新建一个。

## 图谱不可用时

如果当前项目文件夹不在任何 Perforce 工作区内，图谱会提示 **"Perforce Graph is unavailable — is this folder inside a Perforce workspace?"**。让文件夹处于某个 Perforce 客户端根目录下的办法，见 [Perforce 概览与连接](./overview.md#连接是怎么建立的)。
