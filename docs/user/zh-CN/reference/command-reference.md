## 关于"中 / 英"标注

大部分命令在命令面板里显示中文。仍显示**英文原名**的命令都来自内置扩展——它们的扩展清单尚未提供中文，下表列出了其中常用的一批。凡是当前显示英文的，都在名称后用"（英文）"标注，并给出中文释义。

命令面板同时把英文原名收作搜索关键词，所以中文名搜不到时，直接敲英文词通常也能命中。

## 搜索与导航

| 命令面板名称        | 作用                   | 快捷键            |
| ------------------- | ---------------------- | ----------------- |
| 在文件中查找        | 全局搜索，可跨文件替换 | `Ctrl+Shift+F`    |
| 快速搜索            | 浮动方式即时搜索并跳转 | `Ctrl+Q`          |
| 查找                | 在**当前聚焦的编辑器**里查找（含输出面板日志区） | `Ctrl+F`          |
| 替换                | 在当前文件里查找并替换（输出面板只读，无反应）   | `Ctrl+H`          |
| 查找下一个          | 跳到下一个匹配                                   | `F3`              |
| 查找上一个          | 跳到上一个匹配                                   | `Shift+F3`        |
| 转到编辑器中的符号… | 跳到当前文件里的符号                             | `Ctrl+Shift+O`    |
| 转到工作区中的符号… | 跨文件按符号名搜索                               | `Ctrl+T`          |
| 转到定义            | 跳到符号定义处                                   | `F12`             |
| 后退 / 前进         | 沿导航轨迹前后穿梭                               | `Alt+←` / `Alt+→` |

> 查找类命令跟着**焦点**走，而不是跟着当前标签页走：焦点在输出面板的日志区时，`Ctrl+F` 打开的是日志区的查找栏，不会动上方文件编辑器里的查找栏。见 [单文件内查找与替换](../search-navigation/find-in-file.md#在输出面板里查找)。
>
> 输出面板聚焦时 `Escape` 归面板所有：先用来关闭面板内的查找栏（没开查找栏时不做任何事），不再直接跳回编辑器组。

> 更多见 [全局搜索与替换](../search-navigation/global-search.md)、[符号与定义跳转](../search-navigation/symbols-and-definitions.md)、[导航历史](../search-navigation/history.md)。

> Perforce 侧的等价功能为 **Perforce Graph: 查看 Perforce Graph**、图谱内 `Ctrl+F` 的 **Perforce Graph: 聚焦搜索** 与图谱内 `Ctrl+Shift+R` 的 **Perforce Graph: 刷新**。更多见 [提交历史图（Perforce 图谱）](../perforce/perforce-graph.md)。

| Toggle Strikethrough（英文）              | 切换删除线             | 无                              |

| Format Table（英文）                      | 格式化对齐表格         | `Ctrl+Alt+T`                    |

## 远程开发

远程开发的命令归在 **Remote-SSH** 分类下（WSL 命令在 **WSL** 分类）；命令名已中文化，分类前缀仍是英文：

| 命令面板名称                       | 作用                                                                                                                                                                           | 快捷键 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| Remote-SSH: 连接到主机…            | 连接一台主机（或输入 `user@host[:port]`）并打开远端文件夹；列表里也会列出本机 WSL 发行版                                                                                       | 无     |
| WSL: 连接到 WSL…                   | 连接本机 WSL 发行版（单个直连，多个弹出列表）                                                                                                                                  | 无     |
| Remote-SSH: 在主机上打开文件夹…    | 在已连接的主机上另选文件夹打开                                                                                                                                                 | 无     |
| Remote-SSH: 关闭连接               | 关闭到某主机的连接，并关闭该主机对应的窗口；若当前窗口正打开着该主机的工作区，会先弹确认框；关完若不再剩窗口，会自动打开一个本地空白窗口                                       | 无     |
| Remote-SSH: 重试连接               | 重试一条失败的连接                                                                                                                                                             | 无     |
| Remote-SSH: 停止远程服务器         | 停止远端主机上的 server 并断开连接；所有使用该主机的窗口会一并关闭（确认框列出受影响工作区，运行中的会话会再次确认）；若关完不剩窗口，自动打开本地空白窗口；停止后不再自动重连 | 无     |

> 命令面板的搜索关键词同时收录了英文原名，所以用 `Connect to Host`、`WSL` 之类的英文词也能搜到。

> 更多见 [远程开发概览](../remote/overview.md)。

## 帮助与诊断

| 命令面板名称                             | 作用                                                                                                                                                                                                                                                                  | 快捷键         |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| 检查更新                                 | 手动检查有无新版本                                                                                                                                                                                                                                                    | 无             |

| 导出诊断包...                            | 把诊断摘要、近期错误记录与日志尾部打包成 zip                                                                                                                                                                                                                          | 无             |

| 停止 Bug 录制并导出证据包                | 结束录制，选择是否脱敏后打包成 zip 并在文件管理器中显示                                                                                                                                                                                                               | 无             |

| 开发人员：打开进程资源管理器         | 打开进程管理器：以表格树展示本应用全部进程（main、窗口、GPU/utility、extension host、AI agent、终端 pty、tsserver、ripgrep 等）的名称、CPU、PID 与内存占用，约每秒刷新；CPU 高于 90% 的行会高亮；右键行可结束进程（Windows 上等同强制结束）、复制该行或整棵进程树文本 | 无             |

> 反馈问题时附上日志会更容易定位，取日志的步骤见 [排障指南 · 日志在哪、怎么取](./troubleshooting.md#日志在哪怎么取)；问题只在你的机器上出现时，改用 [Bug 录制](./bug-recording.md)。
