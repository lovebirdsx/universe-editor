# 聚焦目录

超大工作区里只保留你关心的几个目录：文件树、搜索、快速打开都跟着收窄，编辑器在后台也少扫一大片。和 `files.exclude` 逐个排除噪音目录相反，这里正面圈定要看哪几个。

## 什么场景需要它

一个几十个顶层目录的大型仓库，你的日常其实只碰 `Client` 和 `Tools/Editor` 这两个。此时排除法不现实：要排除的是几十个"其它"目录，而且每多一个新目录都要再排除一次。聚焦目录把这个过程反过来——只声明你**要看**的目录，其余一律收起：

- 文件树不再长得看不到头；
- 全局搜索的命中不再淹没在你从不关心的目录里；
- `Ctrl+P` 不再在一堆同名文件里挑；
- 编辑器后台不再为整个仓库的改动与索引忙碌。

## 快速开始：聚焦一个目录

1. 在[资源管理器](../editing/explorer-and-files.md)（文件树）里，右键你想留下的目录。
2. 选 **聚焦此目录（Focus on This Folder）**。该目录成为唯一聚焦目录，聚焦模式随之开启。
3. 文件树立即只剩这棵子树；状态栏左侧出现文件夹图标和数字 `1`，表示聚焦已生效。

之后想把别的目录并进来，在[命令面板](../reference/glossary.md#命令面板)运行 **View: Add Folders to Focus...**，在弹出的目录选择框里挑（可多选）。

## 管理聚焦集

- **追加目录**：运行 **View: Add Folders to Focus...**，在目录选择框里挑一个或多个目录（支持直接输入路径）。这是聚焦生效后追加目录的**主入口**——聚焦已经把待追加的目录藏起来了，右键菜单只能操作看得见的东西，所以不够用。
- **追加目录（右键）**：右键另一个目录选 **加入聚焦（Add to Focus）**。仅在该目录当前可见时可用，例如中间的骨架目录。
- **移除目录**：点击状态栏的聚焦计数条目（文件夹图标 + `N`），在弹出的管理菜单里选中要移除的目录；或右键该目录选 **移出聚焦（Remove from Focus）**。移出最后一个目录后，聚焦模式自动关闭。
- **查看当前集合**：鼠标悬停状态栏的聚焦计数条目（`N` 是聚焦目录数），会列出全部聚焦目录。
- **退出聚焦**：点击状态栏后在管理菜单里选 **Exit Focus Mode**，或直接在命令面板运行 **View: Exit Focus Mode**（仅聚焦模式开启时可用）。

> 点击状态栏弹出的是**管理菜单**：上半部分逐条列出当前聚焦目录（选中即移除），下半部分是「Add Folders...」与「Exit Focus Mode」。日常最常做的是加一个、去一个，所以点击不再直接整体退出。

> 若状态栏的计数条目显示的是文件夹图标 + `0`（高亮警示样式），说明 `workspace.focusEnabled` 是 `true` 但集合是空的——此时什么都不会被过滤，界面和没聚焦一样。点这一项，在管理菜单里追加目录或关掉聚焦即可。手写 JSON 或高优先层用 `false` 取消了低优先层的全部条目时会落到这个状态。

> 提示：退出聚焦**不会清空**目录集合——重新开启（把 `workspace.focusEnabled` 设回 `true`）会直接恢复上次的集合。重新输一遍目录，正是这个功能要消除的麻烦事。

通过右键菜单和状态栏做的改动会写进**项目层设置**（工作区里的 `.universe-editor/settings.json`），因此可以随仓库提交，让团队共用同一份聚焦配置。你也可以把同样的键手写进用户全局 `settings.json`，层级与优先级见[设置 · 用户设置 vs 工作区设置](../customization/settings.md#用户设置-vs-工作区设置)。

## 三个设置项

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| `workspace.focusEnabled` | `false` | 聚焦模式总开关 |
| `workspace.focusFolders` | `{}` | 聚焦目录集合：键是工作区相对路径，值为 `true` 才生效 |
| `workspace.focusShowRootFiles` | `true` | 是否仍显示工作区根目录下的直接文件（README、构建脚本这类人人要碰的文件） |

手写 JSON 示例：

```json
{
  "workspace.focusEnabled": true,
  "workspace.focusFolders": {
    "Client": true,
    "Tools/Editor": true
  }
}
```

`workspace.focusFolders` 的写法和 `files.exclude` 一致，所以也继承那套层级语义：**高优先层可以用 `false` 取消低优先层的条目**。例如你在用户设置里聚焦了 `Client` 和 `Server`，某个项目的工作区设置里写 `"Server": false`，那么打开该项目时就只剩 `Client`。

## 路径是怎么解析的

键是**工作区相对路径**，不是 glob。写的时候有几条归一化规则：

- 反斜杠归一成正斜杠，首尾斜杠会被剥掉——`\Tools\Editor\` 与 `Tools/Editor` 等价；
- 嵌套条目折叠到最浅的那个：同时聚焦 `Tools` 和 `Tools/Editor`，等于只聚焦 `Tools`；
- `.`、`/`、空串这类表示"整个工作区"的写法会被丢弃——聚焦整个工作区等于没聚焦；
- 试图逃出工作区的 `..` 路径也会被丢弃；
- Windows 和 macOS 上路径大小写不敏感。

## 聚焦后，什么变了

**你看到的**：

- **文件树**只显示聚焦子树。中间的通路目录会保留——只聚焦 `Tools/Editor` 时，`Tools/` 作为到达 `Editor` 的骨架仍会显示，但它**自己的直接文件不显示**。工作区根下的直接文件由 `workspace.focusShowRootFiles` 控制。
- **配置目录在文件树里始终可见**：根目录下的 `.universe-editor/` 与 `.vscode/` 无论聚焦集与 `workspace.focusShowRootFiles` 怎么设，都留在文件树里——聚焦配置本身就写在 `.universe-editor/settings.json` 里，把它藏起来等于把钥匙锁在柜子里。这个豁免只作用于**文件树的可见性**，也只在**根目录**生效：全局搜索、`Ctrl+P` 与文件监听仍按聚焦集来，`Client/.vscode` 也是普通内容照常过滤。
- **全局搜索**只在聚焦目录里搜；[搜索侧栏](./global-search.md)的包含 / 排除范围在此基础上进一步收窄。
- **Ctrl+P 快速打开**只在聚焦目录里找文件。
- **AI 会话的 `@` 文件引用**只在聚焦目录里给建议（见[你的第一次 Agent 会话](../ai-agent/first-session.md)）。

**编辑器在后台扫的**——这正是性能收益的来源：

- 文件监听只订阅聚焦子树；
- 全文搜索只在聚焦目录里跑；
- 工作区文件名索引只索引聚焦目录。

超大工作区里，这三项正是日常卡顿与等待的主要开销。

## 它不是访问控制

聚焦是**视图约束**：只改变浏览与搜索时"默认展示什么"，不是权限边界。

- 从搜索结果、跳转定义、SCM 变更列表打开聚焦范围外的文件，照常工作；
- 打开后正常显示、正常编辑、正常保存；
- Git 集成（包括仓库探测）同样在真实的工作区根上全量工作，不受聚焦影响。

## Perforce 用户注意

聚焦对 Perforce 用户有一份额外收益：[收集改动（reconcile）](../perforce/daily-workflow.md#收集改动reconcile)的改动徽标检查范围会收窄到聚焦目录——超大 depot 上只查你关心的那部分，扫描成本因此与聚焦范围、而非整个 depot 的规模挂钩。

但 **SCM 操作本身不跟随聚焦**：已签出文件列表（`p4 opened`）、整个 changelist 的还原与搁置仍是全 client 范围，不会因为开了聚焦就变成部分操作。聚焦只影响"扫描"，不影响签出状态的管理。

## 本页涉及的命令

| 命令面板名称 | 快捷键 | 作用 |
| --- | --- | --- |
| 聚焦此目录（Focus on This Folder） | 无（仅右键菜单） | 把该目录设为唯一聚焦目录并开启聚焦 |
| 加入聚焦（Add to Focus） | 无（仅右键菜单） | 把该目录追加进聚焦集（已有聚焦集、且该目录当前可见时出现） |
| 移出聚焦（Remove from Focus） | 无（仅右键菜单） | 把该目录移出聚焦集（该目录已在聚焦集里时出现） |
| View: Add Folders to Focus...（英文） | 无 | 打开目录选择框追加聚焦目录（可多选；不受聚焦过滤影响） |
| View: Manage Focused Folders（英文） | 无（点击状态栏） | 弹出管理菜单：移除某个目录 / 追加目录 / 退出聚焦 |
| View: Exit Focus Mode（英文） | 无 | 退出聚焦模式（仅聚焦模式开启时可用，含集合为空的情况） |
